# 接手者禁区

> 任何接手本项目的壳/模型，动码前必读。以下每条都是 v1 用血换来的或业主明令，**不是建议，是禁令**。
> 你若觉得某条「可以优化掉」——停下，写进 `docs/待业主裁.md`，等业主。不得自行放宽。

## 禁做

1. **禁加任何周期任务**：cron、systemd timer、`for { sleep }`、`time.Ticker`、定时扫表、定时探活、定时快照——全部禁。你需要的是事件；找不到事件源就去造事件源（父进程 SIGCHLD、socket EOF、gRPC 调用），不是加定时器。唯一例外：`time.AfterFunc` 一次性闹钟，且必须随事件重置。
2. **禁心跳**：任何形式的「我还活着」周期信号。活着=连接在；死=EOF/SIGCHLD。
3. **禁 JSON 进入 meta 内部**：接口、存储、事件、配置文件一律 protobuf（配置可用 textproto）。壳 CLI 的 JSON 输出只能在 `adapter/` 包内解析并立即转 proto。
4. **禁 REST / 禁 WebSocket / 禁 SSE**：全链 gRPC；浏览器走 Connect 二进制。
5. **禁在仓库里放票面状态文件**：票只在 SQLite。可以有只读导出，不能有可编辑的 `tasks/*.md` 当真源。
6. **禁第二个写者**：席位/CEO/前端/脚本都不许直写 SQLite；一切经网关 gRPC。
7. **禁在网关里放判断逻辑**：网关只出事件、执闸、路由壳。「该不该杀」「该不该延期」「驳回是否合理」归智能体。
8. **禁席位碰部署树**：施工只在 worktree/独立克隆；部署只由 CTO 实例经项目配方命令执行。
9. **禁施工自审 / 禁 CTO 自审**：审计必须是独立实例。
10. **禁同一时刻两个 CEO 实例**。
11. **禁驳回即换壳**：④级（质量驳回）同壳重做；只有①②③级机器失效才换壳。
12. **禁把人等在席位里**：壳全无交互模式；许可提示自动答拒。
13. **禁引进开源整机**（Paperclip/OpenClaw/Grok Ship/Sortie 等）：只借设计，不借实现——它们全是心跳+JSON+REST。
14. **禁用 Postgres 替换 SQLite**，除非跨机需求出现且业主批。
15. **禁 CEO 记忆依赖壳自带记忆**：记忆在 `ceo_memory` 表。
16. **禁飞书通道挂在 CEO 壳上**：通道归网关。
17. **禁跳过自举阶段验收锚**（总设计 §13）：锚不绿不进下一阶段。
18. **禁在 meta 跑通前登记 O 项目**。

## 遇到以下情况，停手→写 `docs/待业主裁.md`→经 CEO 报业主

- 发现红线之间互相冲突
- 某壳 CLI 根本不支持无交互/流式输出（适配器做不出来）
- 浏览器 Connect 二进制流在业主网络环境走不通
- 需要新增第三方依赖且非 Go 标准库/grpc/connect/sqlite 驱动/protobuf 之一

## 自检口令（每次提交前问自己）

- 我加的东西里有没有「每隔」「定时」「轮询」「心跳」「刷新」？→ 有=回退
- 有没有 `encoding/json` 出现在 `adapter/` 之外？→ 有=回退
- 票状态有没有第二份副本？→ 有=回退
- 网关里有没有 if 在替智能体做决定？→ 有=挪出去成事件
