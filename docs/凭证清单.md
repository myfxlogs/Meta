# 凭证清单（全进 SQL，文件只作迁移源）

> 业主钦定 2026-11-01：「凭证不得写入 env，全部进 sql」。
> 值一律经网关 `Secret(name)` RPC 取，禁入码、禁入 git、禁入票面、禁入对话。本表改动走业主令。

## 存储

- **库**：SQLite `secret` 表——`name`(PK) / `value`(AES-256-GCM 密文 BLOB) / `role_acl`（哪些角色可取）/ `created_at` / `rotated_at`
- **库外只有一把钥匙**：`/opt/meta/run/vault.key`（0600，随机 32B，不入 git、不入票）——解密全部 secret 的主密钥。钥匙丢失=全部凭证须重新录入；钥匙泄露=全部凭证视为泄露
- **写径**：`meta secret put <name>`（CLI 读 stdin）或迁移期一次性导入器；**读径**：席位 gRPC `Secret(name)`，网关按 `role_acl` 放行
- 迁移完成后 env 文件**不再被读**（归档目录原样保留，不回删）

## 权限要求

- `secret` 表值列密文，禁明文；`vault.key` 0600
- 票据/日志/对话/票面禁出现值；席位只经 `Secret(name)` 拿值，不知道加密细节
- 新凭证：`meta secret put`→本表 ACL 加行→提交（三件一套）；**禁** 回 env 文件
