## 1. 过滤壳死因分类（`internal/gateway/patrol.go`）

现状 `cheapFilter` 三处错误出口：`cmd.Output()` 错（合一类）、输出两径
不判。错误原文直接进 `filter_degraded` note——note 即诊断面，改它就够。

新增两个纯函数（可测锚面）：

- `quotaLike(s string) bool`：小写匹配限额签名集——`rate limit`/`429`/
  `quota`/`insufficient_quota`/`daily limit`/`limit exceeded`/`限额`。
  命中＝该输出/错误带限额特征。
- `classifyFilterExit(cctx context.Context, err error, out []byte) string`：
  - `cctx.Err()==context.DeadlineExceeded` → `超时（限 <Filter.Timeout>
    未归被杀）`——CommandContext 超时杀的钦定特征；
  - `errors.As` 得 `*exec.ExitError`：`quotaLike(stderr)` 或
    `quotaLike(stdout)` → `限额打穿 tail=<尾>`；否则
    `退码非零 exit=<code> tail=<stderr 尾300B>`——OOM/外部杀落此桶，
    与超时可分；
  - 其余（Start 败/二进制缺/权限）→ `起壳败: <err>`。

`cheapFilter` 改点：

- `cmd.Output()` 错 → `fmt.Errorf("过滤壳 %s: %s", name, classifyFilterExit(...))`；
- 两径 parse 皆败后：先 `quotaLike(string(out))` →
  `限额打穿（输出不可判＋限额特征） tail=<尾>`；否则
  `输出不可判（无 KEEP/DROP 行） tail=<stdout 尾200B>`。

tail 摘要一律过 `clean()`＋截断（决策67 毒字节进事件流瘫marshal 先例；
`logTail` 同款形制）。`filter_degraded` note 自此带分类词——锚1 机器可判。

## 2. patrol-* 正派发兜底提示（`internal/gateway/dispatch.go`）

现状 `dispatchOnce` 262-272：`PromptFile=="" && InjectRoot!=""`→
`injectPrompt`；`InjectRoot==""`→整段跳过；274-292 D-40 闸。

加巡逻支（注入段后、D-40 前）：

- `spec.PromptFile=="" && strings.HasPrefix(req.ticketID, "patrol-")` →
  `g.patrolDutyPromptFile(ctx, req.ticketID, req.role, t)`（新函数，放
  `patrol.go` 与 `patrolPromptFile` 同族、共用 `patrolFile` 落盘径）：
  内容＝票ID/标题＋spec 八栏（unmarshal 得则内嵌，败则注「spec 读 DB」）
  ＋未投递留言（信号原文）＋轨（诊断→自立案→报告）＋META_DELIVER 双发
  契约——**非 adjunct 口径**（占相位正经席，文案不得写「不占相位」）。
- `injectPrompt` 败：先照旧落 `inject_failed` 事件（不吞错），随后
  patrol-* 续走兜底而非 return——值班票是报信链本体，组装败正是最需要
  报信的时刻。非 patrol-* 票语义不变：注入机缺/败照撞 D-40/返回——那是
  配置故障，该响。

覆盖径：`routeSignal` 正派发、caster `spawn_needed:巡检` 对账补发、手工
`meta dispatch`——所有 patrol-* 无 PromptFile 派发共用 dispatchOnce 一点，
比在 routeSignal 局部补更全。
