# 票 0011：CEO 面五 RPC＋锁＋provenance＋迁移导入＋顺手债包

> **票面**（施工输入）；经 `meta ticket new --spec-file` 入 DB 后派发。
> 对应设计-0007 §4 票面（设计编号「票 0008」）；本票是阶段 3 一切的地基

## 八栏

### 1. 目标

`CeoGateway` 五 RPC 全立（Events 订阅流／SubmitRequirement／Rule／Inquire／
Memory 流）；CEO 锁＝连接登记（一订阅在第二订阅拒、EOF 除名）；事件泵
（ceo_spawn_kinds 配置列 kind→有订阅随流派发，无→`ceoPending`＋内部唤起
无头席）；`ensureCEO` 内部唤起（`Dispatch(role=CEO)` 一律硬拒——禁区#10 码位，
spawn 连败 3→`ceo_last_resort` 事件行）；`seat_run.provenance` 列＋全链盖戳
（戳只取 run 行不取请求自报）；`meta import-legacy` 一次性导入 ceo_memory.md；
顺手债包 D-36/34/37/15/14/38/32 清零；D-22（CEO run 事件数 vs memory 写数
机械比对→`ceo_gap`）；`req_pending` 补边＋对账抑制。

### 2. 为什么

§12 草图与 §8 全权件是阶段 3 地基：无锁无双 CEO（禁区#10 机械落点）、
无戳无真业主令（D9——「业主指示只认 terminal/feishu」自此机检可查）、
无导入无接手门；需求票＝CTO-A 设计票、子票承载施工链的钦定轨（设计 §1.4）
靠本票 admin 帧与 req_pending 泊车成立；D-22 是 CEO 收口门的机器牙齿；
债包顺同码面清（dispatch/attach/seat/inject 均本票动线）。

### 6. 验收锚（全部机器可判，含对抗锚提名）

1. `go build ./... && go vet ./...` 绿；`go test -count=1 ./...` 绿（原文 tee
   机器记录）；`bash scripts/selfcheck.sh` 绿；pb 再生 diff 入档。
2. **锁**：helper CEO-A 订阅 Events 中，CEO-B Events→拒（FailedPrecondition）；
   A 断→B 得；触发 kind 事件→无订阅时 `seat_run` 出现 `role=CEO` run（无头
   唤起）＋二事件不重复 spawn；连败 3→`ceo_last_resort` 行。
3. **provenance**：伪 spawnCEO(prov=`feishu:x`)→其 SubmitRequirement→需求票
   `created`/`requirement` 行 prov=`feishu:x`；席自报 Requirement.provenance
   字段被盖（设 terminal 仍落 feishu:x）；admin create 的子票行同戳；
   `Dispatch(role=CEO)`→硬拒。
4. **Rule**：void→作废边+confirm 两步（无 challenge 拒）；budget_raise→解冻；
   redirect（req_pending 泊车票）→重派 CTO run。
5. **Inquire**→adjunct CTO run 起＋`adjunct_deliver` 回。
6. **Memory**：put/get 往返；`kind=say`→`ceo_say` 行+事件；put 落
   `event_ref=run_id`。
7. **req_pending**：CTO 席 Yield→`已立`+行；对账不补 spawn（抑制闸）；
   `Rule{redirect}` 后重派 CTO。
8. **import-legacy**：fixture md→行（幂等二跑零增）；**D-22**：CEO run 处理
   1 事件零写→`ceo_gap` 行。
9. **admin 帧闸**：role=施工发 admin→拒/断流；adjunct CTO 发→拒；fill_spec
   越票→拒。
10. **债**：D-36 `GetBudget` err→return（变异：注入 err→不再静默）；D-32
    模板末行断言＋helper 无哨兵净退→无 Deliver（死席径）；D-34 emit/append
    序；D-15 终态后 specs/failSet/warned 清；D-14 `meta seat` 基础单测；
    D-38 三断言补齐；D-37 gofmt。
11. **对抗性锚（≥4）**：①锁登记「第二订阅拒」分支删→双 CEO 并存锚红；
    ②provenance「取自行不取请求」行翻→席自证戳锚红；③req_pending 对账
    抑制行删→泊车票被重派锚红；④admin 帧 role 闸删→施工席立票锚红。
