> 脸上，不靠席位自觉翻索引（E15：会忘的规则必须机械化）。

### 1. 目标
派单组装提示时，注入机按票面（Goal/Scope）关键词机械检索 `docs/经验库/*.md`
与 `docs/技能库/*.md`，命中项以「判例前置」段强制插入施工提示；命中>3 截断
top3 并附两库索引指针；无命中不加段。

### 2. 为什么
现状两库只在注入模板里静态引用索引，读不读全凭席位自觉；经验库里的坑重复
踩（哨兵 JSON 包裹 D-42 式）证明「写了没人看」。super-agent 系以 persistent
deep research 拿榜；我们不上模型，关键词检索拿 80% 价值。

### 3. 范围
- 注入机组装处（`internal/inject` 提示装配链）加检索函数：关键词＝票面
  Goal+Scope 分词（中文按 2 字滑窗＋英文整词），扫两库文件名＋正文首段。
- 命中评分＝关键词重叠计数，top3；「判例前置」段格式：路径＋首行摘要。
- 单测：命中/无命中/截断三分支＋注入产物含段实证。

### 4. 禁区

- 定时器/轮询（R2）；检索点只在派单组装时刻。
