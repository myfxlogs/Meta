# 票 0009：守卫簇——路由 role 过滤＋空提示拒起＋席位级死因禁标壳（D-39/D-40）

> **票面**（施工输入）；经 `meta ticket new --spec-file` 入 DB 后派发。
> 本票是 0007 连环事故（决策 52）的机械防线收口，与阶段 3 批次同批但**最优先**——
> 决策 53 已复位自动审派三路由，复位后无人值守链路上的每一张 deliver 都
> 必然再撞今晚的坑，本票不清，后续票全在裸奔。

## 八栏

### 1. 目标

三件一簇（同码面：派发链守卫），全部机械闸：

1. **D-39 路由 role 过滤**：`Route` schema 增 `role` 字段——非空则要求事件
   `role` 等值匹配（deliver 等事件已自带 role，决策 41）；空＝不滤（旧行语义不变）。
   `config/caster.textproto` deliver 路由拆行：`role="CTO"`→只通知不进审
   （设计票交付归 CEO 事后验，决策 49/53）；`role="施工"`→通知＋派审计。
2. **D-40 空提示守卫**：派发解析出的最终 `PromptFile` 为空（无覆盖径且注入机
   关/注入产物为空/文件缺失或零字节）→`spawn_blocked` 事件＋**拒起**，
   不耗壳尝试、不进 failSet、不迁壳健康。
3. **席位级死因禁标壳**：席位外壳自身退码（`ExitSeatErr`/`ExitOrphan`/`ExitAbort`）
   与输入层死因（prompt 文件不可读、适配器构造失败等席非壳之错）→分级为
   **席位级**——事件留痕但**不进 failSet、不迁壳健康**。空输入退码≠壳病
   （0007 三壳秒死误标实证）。

### 2. 为什么

- 决策 52 因果链：CTO 交设计票→deliver 路由只认 kind 不认 role→误派审计
  （无 prompt_file）→注入机在生产网关未开（`--inject-root` 缺省）→
  **空提示**→三壳秒死按壳级入 failSet→`audit_dead` 路由重派循环→耗尽×4。
  三刀止血治标（且决策 53 已复位），本票是每一环的正解。
- 复位后的每一天窗口期，任何施工席 deliver 都会再触发无 prompt 的审计派发——
  守卫落位前，自动审派链是待爆弹。
- 「席位级死因禁标壳」护的是真壳健康账：把网关/外壳/输入错误记到壳头上，
  会让健康壳被冤进 failSet 与健康表，真出故障时无壳可信。

### 3. 范围内

- **proto**：`Route` 增 `string role`（注释：非空则要求 EventItem.role 等值）。
  pb 再生（diff 入机器记录）。
- **`internal/caster`**：`process()` 匹配加 role 闸（`rt.Role != "" &&
  rt.Role != row.Role → continue`，与 kind/note_contains 同位串行）；
  表加载校验不动（role 空＝不滤，无需新拒载项）；匹配/动作单测。
- **`internal/gateway/dispatch.go`**：`dispatchOnce` 在注入段之后、壳路由之前
  加**空提示闸**：`spec.PromptFile == ""`（含注入径未启）→`spawn_blocked`
  事件（note「空提示拒起」）＋return；显式 prompt_file 但文件不存在/读不出/
  零字节→同径（读文件判空属机械判）。
- **`internal/inject`**：`Assemble` 产物 `strings.TrimSpace==""`→返回错
  （防万一；现流程 CheckSpec 已拦空 spec，此为产物级兜底）。
- **席位级死因分级**：`internal/seat` 新增 `ExitInputErr`（输入层：prompt
  文件不可读/适配器 Build 失败，`runChild` 起点返 -1 处改走该码）；
  `ClassOfExit`/`ExitCodeOf` 增设席位级映射（`ExitSeatErr`/`ExitOrphan`/
  `ExitAbort`/`ExitInputErr`→`adapter.ExitWrapper` 新分级值）；网关
  `reportShell` 对席位级**早退**——只落 `seat_err` 事件行（note 带壳名＋退码
  ＋tail 摘要），不进 failSet、不调 `NextHealth`。
- **`config/caster.textproto`**：deliver 拆两行（`role:"CTO"` 只通知
  「设计交付·事后验」；`role:"施工"` 通知＋dispatch 审计）；审计 dispatch
  行补 `prompt_template`（静态审计提示模板——注入机未开期的第二道防线，
  生产止血已先行同改）；新增 `config/caster/audit-review.md` 审计模板
  （角色指引＋`meta events/phase` 自取票面＋`META_VERDICT:pass|reject:<ref>`
  哨兵纪律）。
- 上述全部单测＋对抗性锚（§6）。

### 4. 范围外（禁线）

- 票型显式列/需求票新 kind；设计票→CEO 面路由的**接线路由行**（CeoGateway
  未立，归 CEO 面票落地后经票改表）——本票只立 role 过滤机制＋deliver 拆行。
- `audit_dead`/`spawn_needed` 审计行的语义重裁（决策 53 已复位，维持）。
- 注入机生产启用（`--inject-root` 入单元文件＝部署件，CEO 运维径）。
- 壳健康模型本身（`NextHealth` 表不动）；`specs` 内存语义。
- 自动票径；dsn.fin；Ticker/周期件照禁（R2）。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./...` 绿；`go test -count=1 ./...` 绿（原文 tee 机器记录）；
   `bash scripts/selfcheck.sh` 绿。
2. **role 过滤**：fixture 表含 `role:"CTO"` notify-only 行与 `role:"施工"`
   dispatch 行——伪 AdminGateway 喂 `deliver{role:"施工"}`→捕获 dispatch 审计；
   喂 `deliver{role:"CTO"}`→零 dispatch（只 notify）；空 role 行照旧全匹配
   （回归）。`role` 与 `note_contains` 并存时两条件都过才动作。
3. **空提示拒起**：helper 派发 prompt_file=""＋InjectRoot=""→`spawn_blocked`
   事件行＋**seat_run 零新行**＋failSet 空＋壳健康行零迁移；prompt_file 指
   不存在文件→同；prompt_file 零字节→同；InjectRoot 置位但组装产物空（mock
   Assemble 返 ""）→同。
4. **席位级死因**：helper 席强制 `ExitSeatErr`（如缺 META_* env 路径单测）→
   `seat_err` 事件＋failSet 不含该壳＋`ShellHealth` 行未动；`ExitOrphan`/
   `ExitAbort` 同径断言；`runChild` prompt 文件不可读分支→`ExitInputErr`→同径。
5. **壳级回归**：②a（Transient）仍迁 limited＋failSet；②b（Fatal）仍迁
   dead＋failSet；①（ExitSpawnFail 机器级）仍进 failSet 不迁健康——本票
   只剥「席位级」，壳级语义一字不改。
6. **配置**：`config/caster.textproto` 加载解析全绿；deliver 两行在；
   `config/caster/audit-review.md` 存在且模板渲染含 `{{ticket_id}}`。
7. **对抗性锚（≥3，删/翻指定行测试必红）**：
   a. `rt.Role != "" && rt.Role != row.Role` 等值比较（删→deliver{role:"CTO"}

   b. 空提示闸 `spec.PromptFile == ""` 检查行（删→空提示席被起，锚 3 红）；
   c. `reportShell` 席位级早退分支（删→ExitSeatErr 进 failSet，锚 4 红）。
