## 同级缺口清单（铁令件②一并列出）

1. **DispatchSeat 静默吞错**（`_ = g.DispatchSeat`，reconcile.go:358）——拒因不落账，零新席零事件的沉默面仍在；本票只修「不可派血统」一处，其余拒因（相位闸/去重/锁占用）同样静默。建议后续票面落「拒因 spawn_blocked 账」。
2. **收养席 stall 精度**：按期窗账非闹钟，粒度＝调和周期 60s（T35 已知）。
3. **cli-drive 截断**对账面：三停截断按 run 计数（T30 迁葬后语义），与期窗 cap 是两轨——裁决复位只复位期窗轨。
4. **非 Linux 判死退化**：zombie 判死仅 /proc 径。
