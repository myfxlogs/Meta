# 设计-0030：票级续传＋两级过滤＋巡检席（三件基建）

> 票-0030 设计引用。业主外派件，目标：消灭重派全量重学（单票曾烧 300 万
> token）、便宜模型挡噪声、异常事件自立案；不破零 cron 戒。

## 1. 票级消息续传（①）

问题：同票后续消息/驳回反馈目前只能靠重派新会话传达，新席全量重学环境。

形制（三段）：

1. **`ticket_msg` 表**（新）：id/ticket_id/actor/text/run_id/created_at——
   run_id 空＝未投递；投递成功后盖消费 run。
2. **活席直投**：`AdminGateway.PostMsg`（新 RPC）落行→查票上活 attached
   非 adjunct run→`GatewayMsg.feed` 顺席位流推下；seat 侧追加
   `$META_ART_DIR/inbox.log` 并 stderr 留痕。壳能不能读信箱属壳行为，
   通道契约＝文件落盘（与 exec-resp.log 同构先例）。
3. **重派续会**：adapter 增可选接口 `Sessioner{SessionID()}`（Parse 流内
   捕 session id）与 `Resumer{ResumeOK()}`；`Spec.ResumeSession` 经
   `META_RESUME_SESSION` env 注入。claude 实现：`--resume <id>`；devin/
   opencode 本报不支持（ResumeOK=false）——不猜壳旗。
   seat 捕到新 session id 即发 `SeatMsg.session`，网关落
   `seat_run.session_id`（新列，幂等 ALTER）。dispatchOnce 起尝试前：
   同票同角色最近 run 有 session_id 且本尝试壳同名且壳 ResumeOK →
   换用「续传提示」文件（未投递 msg＋驳回史，不含全量注入）＋
   ResumeSession；其余尝试照旧走注入机。未投递 msg 永远进注入前缀
   （`inject.Input.Msgs`，判决史节后「票内留言」节）——续会只是省学，
   不续会消息也不丢。投递记口：msg 进提示或直投成功即标 run_id。

入站：`meta msg <票> <文本>` CLI→PostMsg。CEO/飞书评注转票内留言属
后续票（范围外记档）。

## 2. 两级过滤（②）

`subscription` 表（新：kind/role 双主键/enabled/created_at）＋配置种子
`subscribe{kind,role}`；GatewayConfig 增 `filter_shell{name,model,
batch_window,batch_max,timeout}`。

emit 末尾 `feedPatrol(e)`：kind 命中订阅→进 patrolCh（非阻塞，满则丢＋
`patrol_drop` 事件）。patrolPump 批收：首事件挂一次性闹钟（window），
满 batch_max 提前冲。批→便宜壳过滤：`runCheapFilter` 把编号事件写提示
文件（run/inject/filter-<ts>.md），adapter.Build 造 argv 起子进程
（限时杀），扫 stdout `KEEP <n>`/`DROP <n>`；无配置/filter_shell.name 空
＝全过；壳调用失败/输出不可判＝**放行全开**＋`filter_degraded` 事件
（信号可用性优先，省 token 是收益不是闸——闸错把真信号埋了更贵）。

## 3. 巡检席（③）

订阅种子（gateway.textproto 落行）：exec_denied/deploy_failed/
spawn_blocked/reject（审计驳回＝phase:reject 边事件 kind "phase:reject"）
/merge_conflict（新 kind，部署闸 integrate 失败点 emit）/patrol_tick
（systemd 心跳注入用）。

信号路由：
- 事件带 ticket_id → `DispatchSeat(t, 巡检, Adjunct)`＋巡检提示文件
  （adjunct 去重闸天然防风暴）。adjunct 提示里给的立案径是
  `meta ticket new --socket $META_GATEWAY_SOCK`——席位 env 已带
  socket 路径，巡检席用 CLI 自立案（票面无 META_ADMIN 改动）。
- 无 ticket_id（patrol_tick）→ 有非终态 patrol-* 票则挂 msg 到该票
  （直投活席/下次续会带走）；无则建 patrol-<ts> 票（内置八栏 spec）
  →正常 DispatchSeat(巡检)（步行边到底，走全相位管线的正经票）。

`meta inject --kind <k> [--ticket <t>] [--note <n>]` CLI→`InjectEvent`
RPC：emit＋AppendEvent（带票才落行）。心跳＝仓内供
`config/systemd/meta-patrol-heartbeat.{service,timer}`（OnBootSec+
OnUnitActiveSec 外源拍，网内零定时器），装件属部署动作不在本票。

## 5. 风险与诚实边界

- claude `--resume` 旗名按 CLI 公开面写；壳版本不支持则该尝试秒退走
  换壳径，不阻塞票（failSet 已有分级）。
- 活席 inbox.log 是文件信道：壳不读＝消息躺文件，续会/下尝试兜底带
  走——不宣称「实时注入壳上下文」。
- 便宜过滤失败放行全开：亏 token 不亏信号；filter_degraded 事件入
  订阅可再被巡检看到。
- patrol_tick 心跳是 systemd timer（外部件），网内仍零 cron——本票
  只供 unit 文件与 inject 径，装机属部署。
