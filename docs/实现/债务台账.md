> **零暗债规则**〔令#E6·2026-11-01，业主问引出，CEO 立规〕：
> 1. **施工**：交付摘要「下一步」节＝**全量遗留申报**（范围内未做／降级实现／绕过路径）——漏报被审计对出＝驳回，**瞒报重于缺陷**
> 2. **审计**：diff 中 TODO／绕过／半成品 与摘要申报对账——对不上＝驳回；对得上＝判决「债项」节列出
> 3. **CEO**：判决债项即时入本账；**派票前必过账**——相关债进新票范围，或显式再延（须理由，防无限滚动）
> 4. 无定时巡账（R2）——滚动检查点＝**每次派票事件**
>
> 状态值：`open`（未派去处）／`planned:<票或事件>`／`accepted:<理由>`（=风险清单式接受）／`ruled:<决策号>`／`done`

## 清债与销号〔令#E7·2026-11-01〕

**债的相位（同构于票，边表钦定）**：

```
open ──拆票引用──→ planned:<票> ──该票判决通过──→ done
open ──CEO 裁接受──→ accepted:<理由>（终态；业主可翻案重开）
open/planned ──决策处置──→ ruled:<决策号>（终态；同上）
planned ──再延（须理由）──→ planned:<新票>   ← 再延计数入条目，K 次（缺省 2）后
                                              只余两出口：本轮票内清，或 accepted 写明后果
```

**消号三规则**：
1. **凭判决销号**：`planned` 债的销号条件＝所指向票的**审计判决通过**；「清于」列必填（票号＋判决档）——无判决指向的销号＝无效
2. **只搬不删**：销号＝条目移「已清」区；台账只增不删，审计面可回溯
3. **分工**：**施工不见台账**（债在票面层就是范围与锚——防挑活）；**审计只验不搬**（判锚绿＝债清，它甚至不需要知道「债」的存在）；**CEO 机械搬运**（凭判决档落笔）——网关立起后：拆票事件机械转 `planned`、判决通过事件机械转 `done`，全程无判断

**验债即验锚**：拆票（CEO/CTO）把债写成该票验收锚的一条，能机器判的必须机器判——债清不清由锚说了算，不由任何人自述。
