## 锚② 实跑主锚：version 第二段含 HEAD 短哈希（互证）

```text
$ cd ~/meta-worktrees/t0048-p1 && go build -o /tmp/meta-vchk ./cmd/meta
$ /tmp/meta-vchk version
meta dev+a3d840c
$ git -C /opt/meta rev-parse --short HEAD
a3d840c
```

第二段 `dev+a3d840c` 含短哈希 `a3d840c`，与 `git -C /opt/meta
rev-parse --short HEAD` 同串——PASS。stamp 段 `dev`＝buildStamp
缺省值（未走 ldflags -X），语义不动；`+a3d840c`＝vcs.revision 前 7。

## 锚③ 降级锚：git/vcs 不可达构建 → `meta <stamp>` 原文退码 0

```text
$ go build -buildvcs=false -o /tmp/meta-novcs ./cmd/meta
$ /tmp/meta-novcs version
meta dev
$ echo $?
0
```

-buildvcs=false 产物无 vcs.revision 键→Short() 返 ""→Version()
退回 stamp 原文 `dev`；输出 `meta dev`、退码 0 不炸——PASS。
（附证：`bin/meta` 11-03 07:49 无戳件同为降级形态活例——构建时
git 不可达静默缺席，非码病。）
