## 4. 施工定夺记因（票面/设计授权项）

- **CatchRows vs EventsAfter**：选 CatchRows 单趟 `ORDER BY id DESC LIMIT`。
  EventsAfter 是升序游标页（`id>since ASC`），取「最新 N 判」须先摸尾
  再倒页两趟起步；DESC 单趟直达且 id 即 rowid 无序排。
- **失格行口径**：设计 §2「自捕失格→不计」直读为整行出分母——拒判
  自身已作外捕计一判，失格标签不再占窗口位。
- **行内文「近 M 判」**：窗口未满时示实纳判例数 M（≤20），不写死
  「近 20 判」——分母如实，窗口上限在口径 note 内。
- **坑档多径分隔**：中英文逗号均分列；段尾句读（。；)）剥除防标点
  入径名成另键。
