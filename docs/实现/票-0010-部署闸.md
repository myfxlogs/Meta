# 票 0010：部署闸＋B2 代跑＋meta 自升级径（audit_pass→CTO-B——闭环最后一只手）

> **票面**（施工输入）；经 `meta ticket new --spec-file` 入 DB 后派发。
> 对应设计-0007 §8 票面（设计编号「票 0012」）；决策 53 提级为本批第二优先——
> 「审计通过→merge＋换装＋健康核验」是当前闭环里最后一只 CEO 的手。

## 八栏

### 1. 目标

`待部署` 票可派 `role=CTO`（部署席 CTO-B）：claim→`deploy_start`→`部署中`；
按项目配方序驱 `SeatMsg.exec_req` 四步（integrate→check→deploy→probe），
网关代跑（`sudo -n -u <run_as>`）→全绿 `deploy_done`→`完成`；任红→自驱
rollback 步→`deploy_failed`→`待部署`＋事件→CEO 裁。B2 降权代跑成立；
meta 项目配方种子落库＋`meta upgrade` 换装径接通；D-2（部署中死先核回滚态）。
`config/caster.textproto` 增 `audit_pass`→dispatch CTO-B 路由行。

### 2. 为什么

§10/B1/B2/D1/D-2：全无人故全机械——部署是闭环唯一还靠 CEO 手工的环节
（决策 53「闭环手清单」：merge+换装＝最后一只手）；代跑执行身份是 vault.key
防线（D1 禁网关自身用户）；meta 自己是第一个被部署项目（配方登记＝自举
闭环，此后票过审即自动部署）。

### 3. 范围内

- **proto**：`SeatMsg.exec_req{step}`／`GatewayMsg.exec_resp`；
  `AdminGateway.Ping`（健康核验径）；`SandboxSpec`（run_as 缺省＋按步覆盖）；
  `project.integrate_cmd` 列；`GatewayConfig.project` 种子消息。pb 再生。
- **`internal/db`**：`project` 表增 `integrate_cmd`（幂等 ALTER）；新表
  `cmd_run{id,ticket_id,run_id,step,exit_code,out_path,tail,created_at}`。
- **`internal/gateway`**：`DispatchSeat` 部署支（闸＝`role==CTO`＋相位
  `待部署`＋deploy 项目锁；claim→`deploy_start`→`部署中`）；
  `handleDeliver` CTO 支（note 哨兵 `META_DEPLOY:done|failed`→`deploy_done`
  →`完成`／`deploy_failed`→`待部署`）；`onRunDead` `部署中` 支（同
  deploy_failed 边＋note「先核回滚态」＋前任 run/日志线索，D-2）；
  exec 帧 handler（闸：`role==CTO`＋票相位=`部署中`＋非 adjunct）；
  项目三锁 `projectLocks[project][design|integrate|deploy]`（内存闸＋启动
  按票相位重建；锁释放→查同项目已立/待部署票补发 `spawn_needed`）；
  design 锁挂「已立→role=CTO 派发」点。
- **`internal/gateway` runner**：查项目配方 step→cmd＋沙箱形制→
  `sudo -n -u <run_as> -- bash -lc <cmd>`；cwd＝干净 clone（`run/deploy/<tid>`，
  runner 以 run_as 自 clone 交付 ref）；超时＝一次性闹钟杀；退码＋输出文件
  路径＋尾段→`cmd_run`＋`exec` 事件行→`exec_resp` 回席；diff 文件清单入
  `cmd_run`（透明非闸）。
- **`scripts/meta-deploy.sh`**（build→`meta upgrade` 换装三件套晋升：候选
  install＋prev 留底＋重启）与 **`scripts/meta-probe.sh`**（`meta ping` 健康）。
- **`meta` 配方种子**：`project` 表 meta 行（integrate=merge 交付支＋check=
  `go build/vet/test`＋deploy=`scripts/meta-deploy.sh`＋probe=
  `scripts/meta-probe.sh`；check 步 run_as=metaseat，integrate/deploy/probe
  按步覆盖 run_as=mluser，sandbox_spec 逐步声明）。
- **`config/caster.textproto`**：`audit_pass` 行补 `dispatch{role:"CTO",
  work_dir:"/opt/meta"}`＋`deploy_failed`→notify＋CEO 触发行。
- 上述全部单测＋对抗性锚。

### 4. 范围外（禁线）

- O 项目配方登记；dsn.fin 部署径；周期探活（探针只跑部署时刻，R2）。
- **sudoers 行编辑＝所需业主动作**（`/etc/sudoers.d/meta-runner`：
  `mluser ALL=(metaseat) NOPASSWD: /usr/bin/sudo` 或更窄限定）——票面明列，
  不代办；`sudo -n` 失→退码＋事件 fail loud，不静默降级。
- 席位直碰部署树的一切其它径（禁区#8——只此 exec 闸一径）。
- run_as 语义扩展：不可信码只进 check 步（metaseat）；配方外命令不得代跑。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./...` 绿；`go test -count=1 ./...` 绿（原文 tee）；
   `bash scripts/selfcheck.sh` 绿。
2. **部署支步行**：helper 席 `role=CTO`：`待部署` 票 claim→`deploy_start`
   事件＋相位 `部署中`；非待部署票派 CTO 部署支→拒；adjunct 席发 exec→拒；
   非部署中相位发 exec→拒。
3. **四步全绿**：伪配方（stub 脚本全退 0）→exec 按序 integrate→check→
   deploy→probe（cmd_run 四行序断言）→`deploy_done`→相位 `完成`；
   `cmd_run` 行含退码/输出路径/tail＋diff 文件清单。
4. **任红回滚**：check 步 stub 退 1→rollback 步执行痕（cmd_run 行）→
   `deploy_failed` 事件→相位 `待部署`（非完成）。
5. **项目锁**：同项目第二张 `待部署` 票派 CTO→锁拒（spawn_blocked/事件留痕）；
   首票终态→锁释→补发 `spawn_needed` 行；启动重建：种子库造 `部署中` 票→
   serve 起后锁在。
6. **run_as**：stub runner 捕 `sudo` argv——check 步 `-u metaseat`，
   integrate/deploy/probe 步 `-u mluser`（按步覆盖断言）；`sudo -n` 非零退
   →`exec` 事件＋退码入 cmd_run（不静默降级）。
7. **D-2**：部署中席死→`deploy_failed` 边＋note 含「先核回滚态」与前任
   run 线索；票回 `待部署`。
8. **健康核验**：`AdminGateway.Ping` RPC 通（CLI `meta ping` 或等价调用
   断言回包）；`meta-probe.sh` 对活网关退 0。
9. **路由**：fixture `audit_pass` 行→伪 AdminGateway 捕 `Dispatch{role:"CTO"}`；
   `deploy_failed` 行→notify。
10. **对抗性锚（≥3）**：a. `deploy_failed` 边映射翻→失败票落 `完成`（锚 4 红）；
    b. rollback 调用行删→红不滚（锚 4 红）；c. deploy 锁查删→双部署并发
    （锚 5 红）；d. exec 闸的相位判等翻→非部署中也能代跑（锚 2 红）。
