### 2.2 票 27 设计：扫尾四件

#### D-19 smoke 声明（两行级）

`scripts/smoke-shells.sh`：`local fail=0 SH T U RUNS FIRST P PID R N D C i`

#### D-20 懒探事件双段化

病位：`dispatch.go onSeatAlive` 探针支（396-403）——attach 即 `SetShellHealth
OK`＋emit `shell_recovered`；探针席随后死在 `reportShell` 又迁 `shell_dead`
——「恢复」先于实证，日志误读（票0002 二审 D-20）。

修法＝恢复只凭交付实证，三段语义：

- `shell_probe_up`（探席立住）：onSeatAlive 探针支——AppendEvent＋emit
  （note=壳名＋探席立住）；**不再 SetShellHealth、不再 emit shell_recovered**
- `shell_probe_ok`（探成）：`handleDeliver` 非 adjunct 各成功回执点前调
  `probeVerdict(ctx, st)`——`st.attempt.Probe` 真→SetHealth OK＋
  AppendEvent＋emit；探针席交付＝壳能干活实证，判决内容无关（reject 也算成）
- `shell_probe_fail`（探败）：`reportShell` 非席位级分支（ExitWrapper 早退
  之后）`at.Probe`→AppendEvent＋emit（note=壳名＋死因级）；`killByGW` 本不
  进 reportShell（`onRunDead:483` 闸）天然免误报；席位级死因早出＝探不出
  结论，不视为败（下轮再探）
- `shell_recovered` kind 退役：全仓 `*.go` 零命中为锚；生产路由表无引用
  （grep 实证），无迁移面
- 新增 kind 的通知面：0021 的 default_notify 种子集落地后补登
  `shell_probe_*`——记本票「下一步」申报，不预写不存在的块（§3.5）

#### D-18 按 run 键分账（纯内存，零 schema）

病位：`handleUsage`（attach.go:201）`countAttempt=!adjunct` 按帧不计源——死
席在途 Usage 帧可晚于下一尝试 `ResetAttemptUsage`（dispatch.go:314）落库，
把上一尝试的消耗计进新尝试帽（票0002 二审 D-18）。

修法＝尝试归尝试的 run 记账：

- `gateway.go`：`curRun map[string]*runState`（tid→当前尝试的活 runState，
  随 `failSet`/`warned`/`frozen` 同址 init）
- `dispatchOnce` 清零块（非 adjunct，`ResetAttemptUsage` 成功后）：
  `g.curRun[tid]=nil`——复位→attach 窗口内旧 run 晚到帧自然失格
- `onSeatAlive` 非 adjunct：`g.curRun[tid]=st`；收养径（`tryAdopt` 成功处）
  非 adjunct 同 stamp——重启后收养的 run 即当前尝试，与 seat_run 真源一致
- `handleUsage`：`countAttempt = !st.run.Adjunct && st == g.curRun[tid]`——
  旧 run 晚到帧只进 `used_total`（真实消耗票级照记，不污染新尝试帽；语义
  与 ResetAttemptUsage「谁复位谁拥有尝试账」一致）
- `onTerminal`（ceo.go:669）加 `delete(g.curRun, ticketID)`——D-15 同址，
  终态不留内存键
- 并发面：g.mu 读写；CEO/CTO 无头席同属非 adjunct——谁复位谁当账，跨角色
  语义自洽（`used` 本来就是票级单计数器）

#### D-6 AST 自检闸（stdlib `go/ast`，零第三方依赖）

- 新包 `internal/repolint`：`CheckDir(root)` 扫 `*.go`（排除 .git/vendor/
  .gomodcache/.gopath/node_modules）→`[]Finding{file,line,kind,msg}`；
  `cmd/repolint` 主程序——命中打印 `file:line kind msg` 至 stderr 且 exit 1
- 两项禁式（补 grep 闸两实证缺口）：
  ① **dot-import 全禁**：`ImportSpec.Name.Name=="."` 任何包——`. "time"` 使
    `NewTicker`/`Sleep` 脱离 `time.` 前缀，grep 闸全瞎（票0001 质询 D-6 指名）
  ② **`<-time.After(` 入循环禁**：`ForStmt`/`SelectStmt`（在 ForStmt 内）的
    `CommClause`/`UnaryExpr` 收 `time.After(` 调用——`for{<-time.After}` 是
    周期型定时器伪装；合法一次性定时走 `time.AfterFunc`/`oneShot`
- `scripts/selfcheck.sh` 末加一行 `go run ./cmd/repolint`（既有 grep 闸保留
  ——AST 是增量不替代；`go run` 构建缓存秒级）
- staticcheck 裁定不引：工具属第三方依赖（禁区「新增第三方依赖→待业主裁」）；
  两实证缺口 AST 已盖；后续若要引，selfcheck 加一行的事——债按 ruled 销，
  评估结论即本档
