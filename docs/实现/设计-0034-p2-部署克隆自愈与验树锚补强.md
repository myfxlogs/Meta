## 1. 残留三件（子票 0042 对象）

### 1.1 残缺克隆永堵（ensureDeployClone 自愈径缺位）

现码 `os.Stat(dir)==dir` 即走同步径（exec.go:318）；克隆中途死
（SIGKILL/OOM/换装重启落在 clone 与后续步之间）或人为残置→
dir 在非 git（或 .git 残损）→fetch 步必败→**每部署同点必复败，
唯人手删目录可解**——与票面「结构性堵死」同族，机制内自愈才对。

修法（钦定骨架，施工可在锚内微调）：同步径 git 步败 **或** dir 位
存在而非目录 → `os.RemoveAll(dir)`＋全量重克隆**一次**；再败照原
fail loud 原文返回（不静默降级、不循环重试）。`repoURL==""` 径
不动（无 git 语义）。

- 边界：dir 恒为 `RunDir/deploy/<tid>` 函数内拼，RemoveAll 不出该域；
  克隆是 repoURL 可全量重建的纯缓存，弃置无信息损失——瞬态 fetch
  败时顶多损一缓存克隆，再败终态与现行同（fail loud）。

### 1.2 疤形测试缺口（生产疤形未进 fixture）

`TestT13_CloneSync` 只覆「fresh clone＋脏残留」。生产实态两疤形无锁：

- **detached-HEAD 旧克隆**（run/deploy/0034 实态）：detached 在交付
  ref 尖＋本地 `<branch>` 在 → 同步后 HEAD 应＝主线顶、挂回本地支。
- **checkout-ref 旧世界克隆**（T13 前径 clone+checkout ref 形）→
  同步后 HEAD 应＝主线顶而非 ref。

fixture 即疤形复刻——删同步径/自愈径对应测试必红（对抗锚位）。

### 1.3 文档漂移：总设计 §10 命令代跑段（总设计.md:281）

`<default_branch>` 顶（检查/部署对象＝并后主线）；交付 ref 仅作
