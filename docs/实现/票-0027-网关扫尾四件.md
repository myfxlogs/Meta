# 票 27：网关扫尾四件——smoke 声明(D-19)/探针双事件(D-20)/run 键分账(D-18)/AST 自检闸(D-6)

> 票面（施工输入）；经 `META_ADMIN:create_ticket` 入 DB 后派发。
> 设计全案＝`docs/实现/设计-0024-债务扫尾批.md`（支 c/0024-design）。

### 1. 目标

清台账扫尾四笔，一处一法：

- **D-19**：`scripts/smoke-shells.sh` `LAST` 未入 `local` 声明、`FIRST`
  声明未用——删 `FIRST` 补 `LAST`（两行级）。
- **D-20**：懒探 `shell_recovered` 单事件「先报恢复后死」——改
  「探席立住→探成/探败」双段：`shell_probe_up`（attach，不翻健康）／
  `shell_probe_ok`（Deliver 实证→翻 OK）／`shell_probe_fail`（未交付先死）；
  `shell_recovered` kind 退役。
- **D-18**：跨尝试 Usage 残竞——按 run 键分账：纯内存
  `curRun map[string]*runState`，旧 run 晚到帧只进 `used_total` 不污染
  新尝试 `used`。
- **D-6**：selfcheck grep 闸两实证缺口（dot-import 绕过、
  `for{<-time.After}` 周期伪装）——stdlib `go/ast` 新包 `internal/repolint`
  ＋`cmd/repolint`，selfcheck.sh 末行接入。

### 2. 为什么

- 决策 76 批清规矩：债无自愈，批清是止损；四笔为台账在账码级最后批
  （0020 批已核销五笔、0021–0023 包走 D-44/46/35/前端深验）。
- D-20：`dispatch.go:399-402` attach 即报 `shell_recovered`，探针席再死
  日志误读（票0002 二审）；恢复须凭交付实证非 attach 口述。
- D-18：`handleUsage`（attach.go:201）按帧不计源，死席在途帧晚于
  `ResetAttemptUsage`（dispatch.go:314）落库→旧尝试消耗计进新尝试帽
  （票0002 二审；窗极窄但修法同窄——一行指针比较永久闭合）。
- D-6：`for{<-time.After}` 与 `. "time"` 使 R2 禁式脱离 grep 视野
  （票0001 质询）；AST 闸补齐；staticcheck 经 CTO 裁定不引（第三方工具
  依赖属业主裁＋边际收益低，裁断见设计档 §1/§3.4）。

### 3. 范围内

- `scripts/smoke-shells.sh`：`local` 行删 `FIRST` 补 `LAST`。
- `internal/gateway/dispatch.go`：
  - `onSeatAlive` 探针支（396-403）：删 `SetShellHealth`＋`shell_recovered`
    两行事件，改先 `AppendEvent` 后 `emit` 的 `shell_probe_up`
    （note=壳名＋探席立住——D-34 序规同守）；
  - `reportShell` 非席位级分支（ExitWrapper 早退之后）：`at.Probe`→
    `shell_probe_fail` 先落行后 emit（note=壳名＋死因级）；席位级死因
    早出＝探不出结论不发 probe_fail；
  - `dispatchOnce` 清零块（非 adjunct，`ResetAttemptUsage` 成功后）：
    `g.curRun[tid]=nil`。
- `internal/gateway/attach.go`：
  - `handleUsage`：`countAttempt` 由 `!st.run.Adjunct` 改为
    `!st.run.Adjunct && st == g.curRun[tid]`（g.mu 下读）；
  - `handleDeliver` 非 adjunct 各成功回执点前调 `g.probeVerdict(ctx, st)`
    （新小函数：`st.attempt.Probe` 真→`SetShellHealth` OK＋AppendEvent＋
    emit `shell_probe_ok`——探针席交付＝壳实证，审计 reject 亦算成）；
  - `tryAdopt` 成功径非 adjunct：`g.curRun[tid]=st`（收养 run 即当前尝试）。
- `internal/gateway/gateway.go`：`curRun map[string]*runState` 字段＋
  构造器 init（与 `failSet`/`warned`/`frozen` 同址）。
- `internal/gateway/ceo.go` `onTerminal`：加 `delete(g.curRun, ticketID)`
  （D-15 同址终态清键）。
- `internal/repolint`（新包）：`CheckDir(root) []Finding`——AST 扫 `*.go`
  （排除 .git/vendor/.gomodcache/.gopath/node_modules）；两项禁式：
  ①`ImportSpec.Name.Name=="."`（dot-import 全禁）；
  ②`ForStmt`/`ForStmt 内 SelectStmt` 循环体收 `<-time.After(` 调用。
  `cmd/repolint`（新 main）：命中打 `file:line kind msg` 至 stderr＋exit 1。
- `scripts/selfcheck.sh`：末行加 `go run ./cmd/repolint`（既有 grep 闸保留）。
- 测试面（落名）：`TestSmokeShells_LocalDecl`（cmd/repolint 或紧邻测试包）、
  `TestShellProbe_Up`/`TestShellProbe_Ok`/`TestShellProbe_Fail`（gateway）、
  `TestUsage_StaleAttemptTotalOnly`（gateway）、`TestRepolint_DotImport`/
  `TestRepolint_AfterInLoop`/`TestRepolint_Clean`（repolint）。

- 不引第三方依赖（`go/ast` 全 stdlib）；不加定时器/轮询/心跳；
  不动部署不并 master；票面不改。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./...` 绿；`gofmt -l .` 零命中；
   `go test ./...` 绿（不破既有基线）；`bash scripts/selfcheck.sh` 绿
   （含 repolint 行）。
2. **D-19**：`grep -n 'local ' scripts/smoke-shells.sh` 行含 `LAST` 不含
   `FIRST`；`TestSmokeShells_LocalDecl` 绿。
3. **D-20**：`TestShellProbe_Up`（probe attach→`shell_probe_up` 事件行＋
   健康未迁）/`TestShellProbe_Ok`（probe Deliver→`shell_probe_ok`＋健康
   =ok）/`TestShellProbe_Fail`（probe 未交付先死、非席位级→
   `shell_probe_fail`）全绿；`grep -rn 'shell_recovered' --include='*.go' .`
   零命中。
4. **D-18**：`TestUsage_StaleAttemptTotalOnly`——run A 为 curRun→复位清
   curRun→A 流注入 Usage→`used` 不增且 `used_total` 增；新 run B stamp
   后 Usage→`used` 增。绿。
5. **D-6**：`TestRepolint_DotImport`（fixture 含 `. "time"`→命中）/
   `TestRepolint_AfterInLoop`（`for{<-time.After(`→命中）/
   `TestRepolint_Clean`（本仓→零命中）全绿；`go run ./cmd/repolint` 本仓
   rc=0。
6. **对抗性锚（删/翻必红）**：
   - `handleUsage` 内 `st == g.curRun[tid]` 比较——删之→锚 4 红；
   - `probeVerdict` 内 `SetShellHealth(..., route.HealthOK)` 行——删之→
     `TestShellProbe_Ok` 健康断言红；
   - `reportShell` 内 `at.Probe` 分支——删之→`TestShellProbe_Fail` 红；
   - `dispatchOnce` 清零块 `g.curRun[tid]=nil`——删之→锚 4 中「复位后旧
     run 帧失格」断言红；
   - repolint dot-import 判定行——删之→`TestRepolint_DotImport` 红。
