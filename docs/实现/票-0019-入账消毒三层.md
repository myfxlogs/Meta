# 票 0019：坏字节预防三层——DB 写面消毒＋壳输出→note 收口＋流出面防崩

### 1. 目标

落地决策 67 D-45 / 决策 68：让「一个坏字节瘫痪全公司事件流」在结构
上不再可能。三层：①`internal/db` 一切写径实参 UTF-8 净化（文本列）
＋spec BLOB proto 校验拒写；②适配器 preview 净化＋rune 边界截断、
壳原始输出进 note 的各收口点净化；③DB→proto 构建点与 emit/流发送
净化＋marshal 预检（坏行替换 bad_row 标记，不返 Internal 崩全流）。
设计全案＝`docs/实现/设计-0018-入账消毒三层.md`。

### 2. 为什么

- 决策 67 实证：`dispatch.go:432` `logTail` 把席位日志尾 300B 原文
  拼进 `seat_err` 事件 note（毒行 394/543）→ `Events`/`EventsAfter`/
  `Observe` marshal 崩 → caster 永久 Internal → 全路由死。
- protobuf v1.36.12 双侧强验 UTF-8：SQLite TEXT 不验、proto 验——
  毒卡中间必炸。净化必须在收口点（db 写面＋proto 构建面），追源无解。
- 同族次伤面：`adapter.preview` 字节截断自制非法 UTF-8；`ExecResp.Tail`
  跨流 marshal 崩；`nt.Spec,_=proto.Marshal(ts)` 吞错存部分 wire；
  board `LatestStages`→`SeatRow` 毒 note 崩板流；`sendPump` Send 败暗死。

### 3. 范围内

- `internal/db/sanitize.go`（新）：`clean(s)`（`strings.ToValidUTF8(s,"�")`）、
  `cargs(args...)`（string→clean，其余原样）、`validSpecBlob`（空→原样；
  `proto.Unmarshal` 败→err；成→canonical marshal）。db 包**一切**
  `ExecContext`/`Exec` 实参过 `cargs`（budget/memory/project/run/secret/
  shell/ticket 全 26 点，含 `tx.ExecContext`；schema/ALTER/VACUUM 除外）。
  `CreateTicketProv`/`UpdateSpec` 的 spec 先过 `validSpecBlob`（败→
  返回错拒写）。`PutMemory` content 按文本净化（`[]byte(clean(string))`）。
- `internal/inject/inject.go`：`ParseTicketMD` 十字段逐一 `ToValidUTF8`。
- `internal/adapter/adapter.go`：`preview` 重写——净化后 ≤n 字节内
  退 rune 边界＋「…」。
- `internal/seat/seat.go`：`scanSentinel` 首行 `line` 净化；
  `sendPump` Send 错落 stderr；`adminSentinel` create_ticket marshal
  败→`nt.Spec=nil`（不存部分字节，stderr 留痕）。
- `internal/gateway/`：`dispatch.go logTail`、`exec.go tailOfFile` 出
  口净化；`admin.go eventItem` 全字段净化、`Events`/`EventsAfter` 逐
  item marshal 预检（败→`bad_row` 顶替）、`Runs`/`Observe` 同法；
  `gateway.go emit` 事件字段净化；`ceo.go ceoEventItem`/`CeoEvents`
  预检、`CeoMemory` get 的 `MemoryRow` 字段净化。
- `internal/board/board.go`：`seatRow`/`ticketRow` DB 源字段净化。
- 测试：设计 §6 所列全部用例落名。

### 4. 范围外（禁线）

- 不改历史数据（10 张被手术改坏的 spec blob 修复走另行径报 CEO）；
  不动角色卡/注入模板/路由表/proto 定义/schema 结构。
- 席位日志/exec-resp.log 等文件原文照存；`ad.Classify` 的 tail 输入、
  `relayExecResp` 落盘行不动。
- 不引第三方依赖（`strings.ToValidUTF8` 是 stdlib）；不加定时器/轮询
  （净化全在写/读/发调用点）；不动部署/不并 master。
