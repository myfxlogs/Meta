# CEO 接机提示词（极简版）

> 仓内 `CLAUDE.md`/`AGENTS.md` 随终端自动加载（席位协议＋读单＋在岗锁都在里面）——**提示词只需一句**：

```
[角色:CEO]
```

- 在 `/opt/meta` 目录开终端，claude/devin 自动读到 CLAUDE.md/AGENTS.md → 默认即 CEO 席（连这一句都可省，首条消息说什么就是什么）；
- 换壳换模型＝同一句；
- 指定其他席位：`[角色:CTO]` 等；
- **双开保护已内置**：接手序列第一步＝在岗检查（`run/ceo-present.json`＋pid 存活探测）——后到者自动转只读并报告，不会出现双 CEO 分脑。
- 自举完成（化身接班令）后本件退役：飞书/终端自动附着。
