## 2. 口径机械表（写死进卡附注，可后调）

判例＝外捕∪自捕两类行。分母＝近 20 判（两类并集按 event id DESC 取 20）。
自捕率＝窗口内自捕判例数/判例数；零判例→「暂无」不显示 0%。

| 类 | 判定式（对 ticket_event 行） |
|---|---|
| 外捕·审计驳回 | `kind='reject'` |
| 外捕·部署失败 | `kind='deploy_failed'` |
| 外捕·巡检立案 | `kind='created' AND ticket_id LIKE 'patrol-%'` |
| 自捕·坑档自报 | `note` 含「坑档：」标签（kind 不拘——deliver/adjunct_deliver/progress 均纳） |
| 自捕失格 | 同 `(ticket_id,坑档路径)` 最新标签行之后、同票出现 `kind='reject'` → 不计 |

去重：同 `(ticket_id,坑档路径)` 多行→按最新行计一次。
非判例行（audit_pass/audit_dead/deploy_done/progress 无标行等）不计入分母。

**已知口径偏差**（写死进卡附注；债级不堵票）：
- 巡检以非 `patrol-` 前缀自立案（`0034-p1` 实证）v1 不可见——后调口＝
  立案径强制前缀，或 created 行补 filer provenance。
- 「同类问题被驳」机械不可判→同票任意后驳即失格（保守向偏低，方向安全）。

## 3. 计算挂点裁定：卡视图装配处 cardView

票授权「卡视图装配处或 caster 消费端，施工定夺并记因」——设计裁定
**cardView**，记因三条：

- **纯读径幂等由构造保证**：卡渲染本就每事件全量重算（无 diff），判例
  分类同为纯函数 rows→rate——同事件重放→同 rows→同值，对抗锚「重放
  不变」零成本成立。
- **caster 径违最小接线**：须新建跨进程信道把比率喂进卡包——新增消费者
  ＋持久值，两份新状态换一个纯函数能做的事。
- **触发零新增**：Observe 一切票事件已重渲；判例变→内容哈希变→PATCH，
  非判例事件重算同值→哈希闸挡 PATCH（R2：零时钟零快照表）。

落点四件：

- `internal/db`：只读件 `CatchRows`（或复用 `EventsAfter` 翻页——施工定夺
  并记因；形态＝单 SQL `WHERE kind IN ('reject','deploy_failed','created')
  OR note LIKE '%坑档：%' ORDER BY id DESC`＋扫描上限）。
- `internal/gateway`：分类纯函数（映射表→窗口 20→去重→失格判→「暂无」
  支）——单测不触 DB（rows fixture 直喂）。
- `internal/gateway/feishu_card.go` `cardView`：调分类→`CardView` 新字段
  预格式化行内文。
- `internal/feishu/card.go` `renderCard`：elements 追加 `**自捕率**：X%（近 20 判）`
  ＋ `{"tag":"note"}` 元素写死口径附注。

## 4. 坑档自报标签约定（「同生标签」载体裁定）

载体＝ticket_event 行 `note` 含「坑档：<repo 相对路径>」（多坑逗号列）。

## 5. 测试锚映射（票§6→用例，设计加两条）

| 锚 | 用例 |
|---|---|
| 注入一拒判→率必变方向正确 | fixture 增 reject 行→分母+1/率降 |
| 同事件重放→数值不变 | 同 fixture 两调输出恒等（构造幂等） |
| 无判例流→「暂无」非 0% | 空 fixture→文案支 |
| 坑档标签＋同票后驳→失格 | 标签行＋后 reject→不计；reject 后再报新径→计 |
| 同 (票,路径) 重复报→去重 | 双标签行→计一次 |
| 映射表对抗 | 每类映射 fixture 至少一行；删 `deploy_failed` 映射→该用例红 |
| 渲染行对抗 | 删 renderCard 自捕率行→快照用例红 |
