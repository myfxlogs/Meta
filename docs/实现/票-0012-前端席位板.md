# 票 0012：前端席位板（Board.SeatBoard Connect 二进制流）

> **票面**（施工输入）；经 `meta ticket new --spec-file` 入 DB 后派发。
> 对应设计-0007 §7 票面（设计编号「票 0011」）；Board 消息/服务自含于本票
> proto，可无依赖并行（设计钦定「可先并行」）。

## 八栏

### 1. 目标

`Board.SeatBoard` 服务端流（Connect 二进制，connectrpc.com/connect/v2）：
接入即一帧全态（DB 组装：活 run＋非终态票＋预算＋最近 stage）→此后事件→
变化帧（seat upsert/seat_gone/ticket upsert 三型，幂等重放安全）。新监听
`--board-listen 127.0.0.1:<port>`（配置 `board_listen`，与 unix socket 无涉）；
token 闸（请求 `token` 字段对 `secret.board.token`，行缺→一律
Unauthenticated fail closed）。`meta board --socket/--connect <url> --token`
CLI 打印流为验收径；`web/board.html` 极简静态页（connect-es CDN 无构建）
为业主面。

### 2. 为什么

§9/R4：浏览器只此一面，只走 Connect 二进制；**不存历史**——过去归 DB 审计面，
板只答「现在谁在哪干什么」；loopback＋token 是钦定最小暴露面。

### 3. 范围内

- **proto**：`service Board`（SeatBoard(BoardReq)→stream BoardFrame）＋消息
  BoardReq/BoardFrame/BoardFull/SeatRow/TicketRow/SeatGone；`GatewayConfig`
  增 `board_listen`。connect-go 生成件（钉 ≥7 天前发布版本，依赖申报白名单内）。
- **`internal/board`**：全态组装（活 run＋非终态票＋预算＋最近 stage）；
  事件→变化帧映射（seat upsert/seat_gone/ticket upsert 三型）；
  事件订阅循环（订 g.events，禁定时）。
- **`meta serve`**：`--board-listen` TCP 127.0.0.1 监听＋token 闸
  （`secret.board.token` 对 `request.token`，缺行全拒）。
- **`cmd/meta`**：`meta board` CLI（打印流，验收径）。
- **`web/board.html`**：connect-es CDN，无构建步；**浏览器连通性先险后试**
  ——施工须先验证页面连通再堆功能（禁区申报点）。
- 单测＋对抗锚。

### 4. 范围外（禁线）

- 历史/分页/查询；HTTPS（loopback 明文+token 已钦定最小集）；网页美化。
- REST/WebSocket/SSE（禁区#4——Connect 二进制是豁免钦定径）。
- 票状态副本（R5：板是投影非状态——一切读 DB 组装）。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./...` 绿；`go test -count=1 ./...` 绿（原文 tee）；
   `bash scripts/selfcheck.sh` 绿。
2. **全态帧**：接入→一帧 full 含伪席/票字段全（run/相位/预算/stage 断言）。
3. **变化帧**：kill 席→`seat_gone` 帧；progress→seat upsert（stage 变）；
   票相位迁移→ticket upsert。
4. **token 闸**：错 token→Unauthenticated；secret 行缺→接入即拒（fail closed）。
5. **端到端**：`meta board` CLI 打印 ≥full＋1 变帧。
6. **对抗性锚（≥2）**：a. full 帧组装行删→接入空板锚红；b. token 等值比较
   行翻→错 token 也放行锚红。
