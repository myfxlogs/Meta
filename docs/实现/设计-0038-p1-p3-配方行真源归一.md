> `SeedProject`「行在即不动」＋运行时 `GetProject` 每步读库＋零合法运行时

## 1. 真源归一裁断（需求裁量项）

票给二选：「DB 行即真源（配置废/仅种子）」或「改码回读配置」。
**本设计取第三解——config 文面为钦定源、DB 为运行时投影**，
理由三层：

- **反向（DB＝真源）不可取**：配置行变「看着像源实非源」的死文案——
  双源歧义反而更深；且须新建配方编辑 RPC＋运维双写纪律，而「票→
  textproto→部署」这条仓内版本化天然写径作废。
- **「改码回读配置」不可取**：exec 每步读文件＝热径解析＋并发撕裂面；
  DB 行失去「派发时刻登记配方」的审计意义（cmd_run 所配即库所存）。
- **本解**：`project{}` 是唯一入径（仓内版本化、走票部署）；DB 行是
  它的启动投影——运行时读径不变、审计语义不丢；「改文件→部署→
  生效」链天然成立（部署必 restart → New() 回种），双源静默漂移
  在启动边界被机械消灭。

## 2. 机制一：启动回种全量覆写＋漂移检出

`gateway.go:299-318` 种子环：

```
for _, ps := range cfg.Projects:
    cur := GetProject(ps.Id)
    drift := diff(cur, seed)          // 五 cmd 字段＋repo_url/
                                      // default_branch/sandbox_spec
    UpsertProject(seed)               // 行无→插；行在且漂→覆写；同文→幂等
    if drift 非空:
        AppendEvent("", "project_recipe_sync", note=<项目:字段清单>)
        emit + stderr                 // 漂移不再静默
```

- 语义钦定＝**文面覆写**（SeedProject「行在即不动」废止，注释/函数
  名更正经——施工裁量实现形）；`UpsertProject` 既有 ON CONFLICT
  全列覆写天然满足。
- `project_recipe_sync` 事件：ticket_id 空（同 ceo_say 空票径）；
  **只在漂移项>0 时产**——零漂移零事件（防每启噪音）。
- 时点安全：回种在 `New()` 内、socket listen 之前——exec 步永远只见
  回种后行，无竞态窗。
- 对账面顺带全行覆盖（sandbox/repo_url 同框比——五 cmd 是票面
  要求域，余字段同漂同报白得）。

## 3. 机制二（不造）：运行时免重启同步径为何零新增

- 已有结论：**配方变更唯一合法入径＝仓内 textproto＋部署换装**。
  免重启 sync RPC/CLI＝给「绕开部署改配方」开旁路，破坏部署闸纪律
  ——钦定不造。
- 当前 DB 漂移修齐径＝**本票自身部署**：deploy→upgrade restart→
  New() 回种→DB＝文面。鸡生蛋无解且无须解：运行中网关是旧码，
  任何网关侧新机制都只能换装后生效。
- 部署后自证：CTO-B/巡检按子票锚7 跑 `sqlite3` 亲验记档。

## 4. 时序与 0041 衔接

- 本票部署→restart→回种：DB rollback_cmd＝**T4 现役文面**
  （MERGE_HEAD→abort+「半合并态已弃净」；无→「显式告警」）。
- 0041 后续部署→其 marker 文面＋tail-scan 同装→restart 回种自动
  再同步：`rollback_aborted` 事件链闭环就位——**二次漂移被机制一
  自然收掉，本票不预写 marker**。
- 残窗记档：设计档级 commit（CTO-A 形态）若直接改 project{} 段
  而未经部署，DB 与文面漂至下次 restart——属票面外非常态
  （配方行属部署基建件，历史无此先例），记残险不建闸。

## 5. 残险与判词

- **shell/subs 种子同族面**：`SeedSubscription`/壳行同「插而不改」
  机制——同漂移病不同表。本票只记档（对账表「下一步」），不修。
- **回种误读风险**：`UpsertProject` 全列覆写含 sandbox_spec——
  种列同 block 一致，无附加风险。
- **多项目**：仅 'meta' 在册；机制对任意 cfg.Projects 行同构。
- **决策81/82 兼容**：merge --abort 弃未完成合并，不动已并历史——
  与「不回退已并历史」原则零冲突（rollback_cmd 文面自体即该原则
  落点，本票不改文面）。
