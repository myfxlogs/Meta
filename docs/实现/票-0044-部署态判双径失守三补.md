# 票-0044：部署态判双径失守三补——死席哨兵排干＋席死径态判＋证据换源

### 1. 目标

按设计档 `docs/实现/设计-0034-p4-席死径态判排干与证据换源.md` 落三补：
① 死席 `sentinel.log` 网关侧排干——挂 attach 席死径与 reconcileActor
部署中死席径两判点，末条 `META_DEPLOY:` 哨兵定边（done→deploy_done，
failed→deploy_failed）；② attach.go 部署中席死分支 transition 前置
两级判（无终哨兵→deployStateOK，绿→deploy_done＋放 integrate/deploy
双锁）；③ deployStateOK「已装」证据换源——exec 日志「已装」行＋
装着戳对期戳为必需件，cmd_run 行降为旁证，socket Probe 保留。

### 2. 为什么

0034 部署四步物理全绿（integrate/check×2/probe×2 皆 exit=0，
upgrade 实装 83ef07a-deploy，restart 后 socket 健），席死径
attach.go:558-563 零判据直翻 deploy_failed（事件 14701）——
`META_DEPLOY:done` 在死席 sentinel.log 上被蒸发，cmd_run deploy 行
因 rec() 在 cmd.Wait 后而 restart 径结构性不落库（全史 37 行零
deploy 步实证）。态判只挂对账单点＋判据源在唯一适用场景不存在＝
「物理全绿翻负」机制性必现。

### 3. 范围内

- `internal/gateway/attach.go`：`case db.PhaseDeploying:` 席死分支
  transition 前置两级判——先排干死席
  `filepath.Join(g.cfg.RunDir,"artifacts",st.run.RunID,"sentinel.log")`
  取末条 `META_DEPLOY:` 行（done→`transition(完成,EdgeDeployDone)`
  ＋`emit(deploy_ok)`＋`releaseProjectLocks(integrate,deploy)`＋
  `cancelAlarm`→return；failed→deploy_failed，note 记哨兵在盘）；
  无终哨兵→`deployStateOK` 绿同上 deploy_done 序、非绿照旧
  deploy_failed（现 note 文案不变）。
- `internal/gateway/reconcile.go`：`reconcileActor` PhaseDeploying
  死席分支同挂排干（死 run 的 RunID 推 artifacts 径，同函数复用）；
  `deployStateOK` 换源——已装证据＝cmd_run 末次 deploy exit=0 行
  **或**最新 `run/exec/<tid>-deploy-*.log` 含「upgrade: 已装 <new> →
  <install>」行（二取一，俱无则假）；stamp 比对＝`<install> version`
  第二段==期戳（期戳首选已装行 NewBin 文件 version——相对径相对

- 排干/取戳 helper 落点与函数形施工定（锚管行为不管名）——可
  attach.go 内私函或 gateway 包新文件；`config/gateway.textproto`
  如需参数随改。
- 测试面：attach 径席死×哨兵 done/failed/无×态判真假、reconcile
  径死席排干、deployStateOK 换源真假支——Probe/stamp/日志面经缝
  桩测，沿用 internal/gateway 测试包约定。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./... && go test -count=1 ./...` 全绿
   ＋`gofmt -l internal/` 零输出（既有测试回归不退）。
2. **attach 径哨兵定边**：部署中票＋席死＋该席 sentinel.log 含
   `META_DEPLOY:done`→事件史见 deploy_done/完成（非 deploy_failed）
   且 integrate/deploy 双锁释；含 `META_DEPLOY:failed`→deploy_failed。
3. **attach 径态判兜底**：席死＋sentinel.log 无 META_DEPLOY 行＋
   态判三要件齐（exec 日志已装行/装着戳==期戳/Probe 绿经缝桩）→
   deploy_done；三要件任一翻→deploy_failed。
4. **reconcile 径排干**：PhaseDeploying 死 run＋sentinel.log 含
   done→deploy_done（boot 序 Probe 不挡——排干先于态判）。
5. **deployStateOK 换源**：cmd_run 零 deploy 行＋exec 日志含已装行
   ＋装着戳==期戳→true；同布景删已装行/戳不符→false；cmd_run
   deploy exit=0 行在（旁证通道）→证据件真。
6. **对抗提名位（删/翻必红）**：sentinel 末哨兵取行行、stamp 判等
   行、deploy_ok 锁放行——任一删/翻则对应测试必红（防「席死恒
   deploy_ok」弱化）。
7. **签名绝迹**：物理全绿布景（已装行＋戳对＋done 在盘）席死→
   票事件流不得出 deploy_failed。
