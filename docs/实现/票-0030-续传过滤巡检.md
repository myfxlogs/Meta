# 票 30：票级续传＋两级过滤＋巡检席（外部施工输入）

> 票面八栏（§6.1 契约序）；设计档＝设计-0030-续传过滤巡检.md。

### 1. 目标

三件基建：①票据级订阅续传——同票后续消息路由回在干席位续上下文，
不开新会话清零；②两级过滤——事件流先过便宜模型筛噪声，信号喂贵席；
③巡检席——事件种类→席位订阅表，命中过滤后真信号自立案/起诊断；
系统静默期心跳由 systemd timer 外部注入事件，网内零 cron。

### 2. 为什么

当前每次重派全量重学环境，单票烧过 300 万 token；异常类事件
（exec_denied/deploy_failed/spawn_blocked/审计驳回/merge 冲突）靠
人发现；静默期无任何活性证据。

  批收→便宜壳过滤→adjunct 巡检派发/巡检票）；dispatchOnce 续传分支；

  壳行；config/systemd/meta-patrol-heartbeat.{service,timer} 供件。
- 测试锚入 internal/{gateway,seat,adapter,db}。

### 4. 范围外（禁线）

- 不动哨兵行契约（META_DELIVER/META_EXEC/META_ADMIN/META_VERDICT/
  META_DEPLOY/META_RULE 独立行语义与配对去重）。
- 不动 handleAdmin 闸（巡检立案走 CLI meta ticket new，不开 admin 洞）。
- 不装 systemd unit、不部署、不并 master、不碰 run/ 下活件。
- 不引新 Go 依赖；不给 devin/opencode 臆造 resume 旗。
- CEO/飞书评注自动转票内留言、feishu 回复线程挂票——记档留后票。

### 6. 验收锚

1. claude Build 带 ResumeSession→argv 含 --resume <id>；init 行
   session_id 被捕；无 ResumeSession 时 argv 不变。
2. PostMsg：活席收 Feed 帧（伪流断言）；seat 收 Feed→inbox.log 追加
   原文行；无活席则消息留行待下次注入带走。
3. dispatchOnce 续传：同票同角色前 run 有 session_id＋壳同名＋
   ResumeOK→本尝试 PromptFile 换成续传件且 META_RESUME_SESSION 注入；
   壳不同名/不支持→注入径不变；未投递 msg 进注入前缀「票内留言」节。
4. 订阅匹配：emit kind 命中订阅行进 patrolCh；不命中零成本。
5. 便宜过滤：KEEP/DROP 解析正确；壳缺席/输出不可判→全放行＋
   filter_degraded 事件。
6. 信号路由：带票信号→adjunct 巡检派发（同票同角色去重）；无票信号
   →有活 patrol-* 票挂 msg，无则立 patrol-* 票＋DispatchSeat。
7. InjectEvent：emit+带票落行；`meta inject --kind patrol_tick` 可手跑。
8. 对抗锚：删 feed 推送/删 session 上报/删 KEEP 解析/删订阅匹配→
   对应锚红。
