# 票 0039-p1：票事件去抖唤醒对账闹钟——立票点火洞收口施工支

> 需求票 0039 拆出（CTO-A，spawn_needed 对账补发·设计锁释放）。设计档
> `docs/实现/票-0039-立票点火洞-事件唤醒对账.md`（决策 91）为唯一设计源。

### 1. 目标

`internal/gateway` 落「票事件去抖唤醒对账闹钟」：任意 `ticket_event`
落账成功（**含 `CreateTicketProv` 写入的 `created` 行**——本票存在理由）
→ 重置一次性闹钟（`armPatrolIdle` 钦定同形制：`time.AfterFunc` 重置式、
mutex 保护、closed 判）；醒 → goroutine 内 `g.reconcile(ctx)`（既有幂等
径不改判别）。去抖窗进 `config/gateway.textproto`（缺省 30 秒）。裸立票后
无人工、无重启，票必进流程。

### 2. 为什么

- `created` 是全表唯一无路由事件：裸立票（`meta ticket new` /
  AdminGateway.CreateTicket）无点火载体，滞留已立——0037/0038 实证，
  0039 自身三连 `spawn_needed` 对账补发亦是同洞（唯有重启对账才够得着）。
- 一处修全局免疫：派发重试耗尽、锁释补发漏发、任何未来新增滞留形态，
  醒来对账即自愈——reconcile 本具全相位「相位×预期行动者」判别表，
  `patrol-*` 票不误派 CTO。
- R2 合规：被叫醒合法（事件重置一次性闹钟），零周期、零快照表，与
  `armPatrolIdle` 同钦定形态。

### 3. 范围内

- `internal/gateway`：一次性去抖闹钟（`Gateway` 字段＋arm/重置方法，
  形制照 `armPatrolIdle`：`g.mu` 保护、`g.closed` 判、`timer.Reset` 复用）；
  醒 → `go g.reconcile(context.Background())`（闹钟回调内起 goroutine，
  不阻塞事件径）。
- 触发挂点：**全部 ticket_event 落账成功径**——`db.AppendEvent` 与
  `CreateTicketProv` 内的 `created` 行同盖。首选 db 层统一挂点（如
  post-insert 回调字段由网关注册——一处盖所有调用方含未来新增）；
  备选＝网关侧逐调用点包装。何形由施工定，`created` 行必触发不可漏。
- `config/gateway.textproto`：去抖窗键（如 `reconcile_debounce`，缺省
  30s）＋`internal/gateway` 配置结构映射。
- 单测（`internal/gateway` 测试件）：①立票→闹钟必设→醒后
  `spawn_needed` 补发、票相位离已立；②窗内多次事件→对账只跑一次
  （可计数断言）；③醒时无滞留→空转无害（零相位变）。
- 演练实证档 `docs/实现/演练-0039-事件唤醒对账.md`：scratch 库真网关
  裸立票→自动离已立全链事件流贴档＋窗内连立两票去抖合并证据。

### 4. 范围外（禁线）

- 周期轮询/cron/固定间隔重扫/快照表——R2 红线；新路径零
  `time.Tick*`/`time.NewTicker`（selfcheck 机械闸全仓含测试）。
- `reconcile.go` 判别逻辑本体、`spawnLine`/`roleForPhase` 文案——只加
  触发不改判别；`对账补发: ` note 是播报员路由契约，一字不动。
- caster 路由表加 `created` 路由——会把 CTO 误派 patrol-* 票（经验库
  `2026-11-02-立票不点火` 规约 2）。
- 历史滞留票批量回填、通知面/卡面新增、相位机新边、emit/订阅道语义。
- `db` 既有写入语义——挂点只可追加读侧回调，不改行内容/成败语义。

### 6. 验收锚（全部机器可判）

1. **演练主锚**：scratch 库真网关环境下 `meta ticket new` 裸立一票
   （非 patrol-*）后 ≤ 去抖窗＋5 秒：`ticket_event` 出 `spawn_needed`
   行且票相位离「已立」——全链零人工零重启（事件流贴演练档）。
2. **去抖合并锚**：窗内连立两票→对账只醒一次（演练档贴判别据＋单测
   注入计数 reconcile 调用＝1）。
3. **patrol 判别锚**：`patrol-*` 裸立票醒后补发消费侧派巡检非 CTO
   （spawn role/事件 note 断言）。
4. **对抗锚（删之必红）**：新路径零 ticker——
   `git grep -cE 'time\.(NewTicker|Ticker|Tick\()' <支顶> -- '*.go'`＝0
   且 `bash scripts/selfcheck.sh` 绿；单测中删闹钟重置/挂点任一行，
   ①或②必红。
5. **配置锚**：键缺/未设→30s 生效；设值→按设值（单测断言 arm 时长
   随配置变）。
6. **单测锚**：①created→armed→wake→补发＋离已立；②窗内 N 事件→
   1 醒；③空醒无害——三测名可 grep。

### 8. 交付形制

支名 `t/0039-p1-event-wake-reconcile`，自 master 新切独立 worktree
施工；commit 信息 `t0039-p1: <一句话>` 写为什么；交付＝推支（不并
master，推 origin）；末行哨兵 `META_DELIVER:<commit>` stdout 独占一行
＋原文追加 `$META_ART_DIR/sentinel.log`（D-42 双发）；交付摘要五节
（新增/修改面→指向文件、根因、验证→引机器记录、下一步全量遗留、
可沉淀打法）＋收口两步门。**不部署**——判决过后随批走部署闸
（设计 §8：下批随 0034 同批）。
