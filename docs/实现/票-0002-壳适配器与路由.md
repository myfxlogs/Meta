## 八栏

### 1. 目标
网关能以**真壳席位**跑票：三壳适配器（devin/claude/opencode）、壳路由与失效分级、预算计量与硬顶、进度帧闹钟——「杀 devin→自动换 claude 重做」一镜到底可测。

### 2. 为什么
阶段 1 钦定交付（总设计 §13）；正面回答风险清单「纸面」三问（前台 exec／流带不带用量／无交互真不问）；阶段 2 三席自举的前置。

### 3. 范围内
- `adapter/` 包：统一适配器接口（**起／流读／用量／退码**四件）＋三壳各自实现；壳 CLI 的 JSON **只在本包**，即解即转 proto（禁区#3）
- 壳路由：登记表（壳×模型×角色×优先序×健康态）；处置分级 ①秒退换壳 / ②a 限流错峰 / ②b 标死换壳懒探 / ③无进度与预算尽→事件
- 预算：用量累计上报；尝试内 80% 警 / 100% 硬停；**票级累计硬顶→`budget_frozen`**（先杀后冻；冻结同时取消该票未决闹钟与排队事件——决策 8/10 钦定细则）
- 进度闹钟：30min 一次性、随 Progress/Usage 帧重置、响→stall 事件（内部事件径即可，CTO 裁决实例阶段 2 接）
- spawn 集成：run token 注入＋per-seat UDS 收养接**真壳进程**（骨架已有，接真）
- 决策 10 遗留三项：① 锚 4 措辞改「可打开且表数一致」 ② §5.3 对账表补「已立」行 ③ `armAlarm` 两锁间窄竞修复
- `scripts/smoke-shells.sh`：真壳冒烟脚本（与默认测试分离）

### 4. 范围外（禁线）
- CEO 面／前端面／外部面／飞书；角色卡与票面注入纪律（阶段 2——本票注入任意给定 prompt 文本即可）；命令代跑；部署闸与回滚态；自动票径；CTO／审计／施工真实角色流

### 6. 验收锚（全部机器可判）
1. `go build ./... && go vet ./...` 绿；`go test ./... -count=1` 绿；selfcheck 绿
2. 适配器解析单测×3 壳：录制样本驱动（起、流帧、用量、退码各自解析正确）
3. 路由表驱动单测：①/②a/②b/③ 处置＋懒探＋健康态迁移逐格
4. 预算单测：80% 警／100% 硬停／票级硬顶三闸＋冻结序（先杀后冻）＋冻结取消未决事件
5. 闹钟单测：无帧超时→事件；帧到重置；重启重算不回归（阶段 0 锚 e 不许退化）
6. **对抗性锚**（令#E5）：提名路由优先序比较行与预算阈值比较行各一处——删之或翻转之，对应测试必红
7. **真壳冒烟（live，独立脚本 `scripts/smoke-shells.sh`）**：三壳各起一真会话——收 prompt→产出→正常退出→用量读到数值；读不到＝如实标「不可得」记入报告，**禁估算造假**。脚本退出码即判据
8. **换壳一镜到底（live）**：spawn devin（冒烟 prompt）→SIGKILL→网关自动换 claude 重起→claude 正常收尾；全程相位变迁与 `seat_run` 记录可查
   （live 锚烧真钱：施工自测各壳至少一次，输出留档供审计复核；不进默认 go test 路径）
