# 票-0053 部署重试径三缺（决策117 立｜0050/0051 空转出血实证）

### 1. 目标

部署支票卡进 blocked 后恢复确定性重试径：机械四步（CliDrive）可达、死壳签名可辨、人工态不空转——三缺一并真修。

### 2. 为什么

2026-11-04 午 0050/0051 实证（决策117）：
- blocked 票 `resume`→部署中→调和补 claude AI 席→429 死→记一账→计数 2>cap=1→回 blocked，确定性死循环两票全灭；`rule redirect` 拒「非 req_pending 泊车态」；`meta deploy` 相位闸拒「blocked 不可派 CTO（部署支=待部署）」——**部署票一进 blocked 除 resume 外零机械径**。
- CliDrive 钦定径仅在 `deriveSpec`（reconcile.go:439）`phase==待部署` 置位，部署中/blocked 票补席永不走机械径。
- 两票 blocked 期间 stall_suspect 仍触→每数分钟派 CTO 裁决席→「簿记假阳性」裁决→死→再触，纯烧额度（事件 21892–21924 链）。
- claude 后端 429「[1310][您已达到每周/每月使用上限，您的限额将在 2026-11-09 13:43:49 重置]」不入限额特征→壳不标 limited/dead→派单死选 claude（devin 候选在列仍落空）。

### 3. 范围内

1. **blocked 部署票机械重试径**：部署支补席统一 CliDrive——`deriveSpec` 的 CliDrive 置位从 `phase==待部署` 放宽到部署支（待部署/部署中）；或 blocked 票加「重试」边回待部署再派。二选一 CTO 定。
2. **claude/GLM 限额签名入特征集**：「您已达到每周/每月使用上限」「使用上限」类签名入限额特征集→shell_limited/shell_dead 账正常落→换壳。
3. **blocked 票停滞不派席**：stall_suspect 对 blocked 相位票不派裁决席（相位闸）。

### 4. 范围外（禁线）

- R2′（禁加周期任务/心跳——相位闸/签名集皆事件面改）。
- cap 值不动（deploy_failed rollback cap=1 不动）。
- T48/T49 去重径（reconcile/attach 两径电平→边沿化）不动。
- 不改壳登记种子 priority 语义；不改配置表（表改动走票外）。
