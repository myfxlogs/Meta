# 席位协议（总档·票0031①）

> 唯一真源归此档＋`internal/seat/seat.go`、`internal/adapter/`、`internal/inject/`。
> 契约分四层：**META_* 哨兵行**（壳→外壳，独立行机械钦定）、**META_* 环境变量**
> （外壳→壳/子进程注入）、**提示模板**（注入机组装件）、**收口门**（退场形制）。

## 一、哨兵行（壳输出最后单独一行；流/文件双发契约 D-42）

外壳扫描面＝适配器解析后**文本流**＋`$META_ART_DIR/sentinel.log` 文件增量
泵（值类文件源优先、动作类流↔文件原文配对去重）。净退无交付哨兵＝席死径
（ExitSeatErr，令#E15/D-32）。

| 哨兵 | 行形 | 语义 | 消费端 |
|---|---|---|---|
| `META_DELIVER:<ref>` | 值类 | 交付哨兵（非审计席净退闸；ref＝commit/支） | seat→Deliver 帧 |
| `META_VERDICT:<pass|reject>:<ref>` | 值类 | 审计席判决哨兵（净退闸，verdict 必填） | seat→Deliver.verdict |
| `META_DEPLOY:done|failed` | 值类 | CTO-B 部署支交付哨兵（选 deploy_done/failed 边） | seat→Deliver note |
| `META_RULE:<action>:<note>` | 动作类配对 | adjunct 裁决席裁决回流（kill_requeue|defer） | seat→Rule 帧 |
| `META_ADMIN:<动作>|<args>` | 动作类配对 | 非 adjunct CTO 席写径：fill_spec/create_ticket/set_project/dispatch | seat→SeatAdmin 帧 |
| `META_EXEC:<step>[ <ref>]` | 动作类配对 | CTO-B 部署支命令代跑请求（三重闸后 sudo/笼代跑） | seat→ExecReq 帧 |

## 二、META_* 环境变量（外壳/闸注入）

spawn env（dispatch.go trySpawn 装配）＋代跑 env（exec.go）＋席位 env：

| 变量 | 注入方→消费方 | 语义 |
|---|---|---|
| `META_SHELL` / `META_MODEL` | 网关→seat | 本尝试壳行 |
| `META_ROLE` | 网关→seat | 席角色（闸选边真源之一） |
| `META_PROMPT_FILE` | 网关→seat | 提示文件路径（stdin/--prompt-file 等价径） |
| `META_WORKDIR` / `META_ART_DIR` | 网关→seat | 工作目录/产物落点（inbox.log、exec-resp.log、sentinel.log 均其下） |
| `META_GATEWAY_SOCK` / `META_SEAT_SOCK` / `META_RUN_TOKEN` / `META_RUN_ID` / `META_TICKET_ID` | 网关→seat | 连接五件套（ticket 空串仅 CEO run） |
| `META_INTERACTIVE` | 网关→seat | =1 stdin 直透（CEO 交互面） |
| `META_ADOPT_GRACE` | 网关→seat | 收养等待秒数（缺省 600） |
| `META_RESUME_SESSION` | 网关→seat | 票0030 续会锚（壳支持续会才注入） |
| `META_EXEC_STEP` / `META_EXEC_REF` / `META_PROJECT` / `META_TICKET_ID` / `META_GATEWAY_SOCK` | 网关→代跑步 | 部署闸步上下文（exec.go envs） |

## 三、提示模板六件（产出径＝注入机组装序/派发点落盘）

| 模板 | 产径 | 内容序 |
|---|---|---|
| 1. 席位注入前缀（全量） | `inject.Assemble`→`run/inject/<票>-<role>.md` | 角色卡→票面八栏+附→判决史→**票内留言**→项目配方→经验库索引→技能库索引→工作目录→交付哨兵（钦定末行） |
| 2. 续传提示件 | `resumePrompt`→`run/inject/<票>-<role>-resume.md` | 续传头→未投递票内留言→判决史→哨兵重申 |
| 3. adjunct 巡检提示件 | `patrolPromptFile`→`run/inject/patrol-*.md` | 信号原文→诊断/立案规程→哨兵重申 |
| 4. 巡检值班票 spec | `patrolTicketFor`（内置八栏） | 处置目标/依据/范围/禁线/引用/锚/验证/交付 |
| 5. 便宜过滤提示件 | `cheapFilter`→`run/inject/filter-*.md` | 判定契约（KEEP/DROP 行首）＋编号事件清单 |
| 6. CEO 无头化身模板 | `config/caster/ceo-headless.md`（{{kind}} 等占位） | caster/ensureCEO 渲染 |

## 四、收口门（令#E9/E10 全席位）

退场前缺一＝半交付：①**事实归位扫描**——坑→经验库（即写）、技能
新证→技能库、裁断→判决史/摘要，私有记忆不得独存项目事实；②**工作
区净**——无未提交改动、交付按形制落位（支/commit/哨兵行）。机械牙：
席位净退无哨兵＝不交付；CEO 收口跑 `scripts/close-audit.sh` 自证。
