> 本轮巡检 run=f884761ec8bc78d8。

### 1. 目标

施工中相位、行动者角色为 CTO（req*/设计票的 CTO 席在施工中续跑，D-51/54
已载三类行动者混居）的票，席位死后对账回队**不得撞未登记边**——须有
合法转移＋事件留痕＋补发，禁止当前「静默 return、零事件、零告警、
票永楔死」结局。

### 2. 为什么

- `internal/gateway/reconcile.go` reconcileActor PhaseWorking 分支
  （:162-181）：`actorRole=="CTO"` → `to=PhaseCreated, kind=EdgeDesignDead`。
- 边表 `internal/db/phase.go:60-90`：EdgeDesignDead 唯一登记边为
  `{PhaseDesigning, PhaseCreated, EdgeDesignDead}`；`{PhaseWorking,
  PhaseCreated, EdgeDesignDead}` **不在表** → `db.Transition` 返
  `ErrIllegalEdge` → `reconcile.go:199-201` 直接 `return`——错误被吞：
  无事件、无 requeue、无 spawn_needed、无 seat_dead、对账路径不
  rearm 闹钟。
- **实证**：票 0038-p1-p2（施工中，meta 项目 B1 孤儿锁 P1 修票）CTO 席
  `681dc24bc2d4434a`（devin/swe-2-max，pid 4068029）死后——seat_run
  dead=1、pid 已逝、adopted_at≈15:39（与末条 adopted 事件 4743 吻合），
  之后每轮对账静默空转：票事件 id>4743 零条，停摆 ~2h 系统零告警。
- **不对称铁证**：`attach.go:551-552` SIGCHLD 死径同相位统一走合法
  `{PhaseWorking, PhaseAssigned, EdgeRequeue}`——两径同语义不同边，
  必有一错；对账径 D-51/54 角色分辨本意（CTO 死回已立补 CTO-A）落空。
- 伴生实害：本修票停摆 → B1 孤儿锁病灶不除 → 待部署队列
  （0034/0036/0034-p2/0037-p2/0038-p1/0041/0042）spawn_blocked 连发不止
  （事件 9400 后已 500+ 条）。

### 3. 范围内

- reconcile.go:170-181 角色分支的边选择合法化——换已登记边或边表补
  登 `{PhaseWorking, PhaseCreated, EdgeDesignDead}`（取舍以施工派发前缀
  与 D-51/54「回已立补 CTO-A」语义为准）。
- 转移失败的非静默化：reconcile 吞错路径（:199-201 同款各 return 点）
  至少落一条诊断事件——转移失败不许零留痕。
- 0038-p1-p2 解锁：修好后其对账应自然回队补发；若相位残留需人工裁决
  归 CEO，本票只把机制修通。

### 4. 范围外（禁线）

- 不改边表其余边；不替 CEO 对 0038-p1-p2 相位做人工裁决。
