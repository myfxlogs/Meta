# 票 0015：票→项目挂接线（NewTicket.project 落地＋挂接闸＋存量回填 RPC）

> **票面**（施工输入）；经 `meta ticket new --spec-file` 入 DB 后派发。
> 设计：`docs/实现/设计-req-9ce5-票挂项目.md`（需求票 req-9ce5efb2e4ad）。

## 八栏

### 1. 目标

`NewTicket.project` proto 字段落地＋挂接全链接线：立票三径
（`CreateTicket`/`CeoSubmitRequirement`/SeatAdmin `create_ticket` 空则继承
本票）＋派发径（`DispatchReq.project`→`DispatchSeat` 取锁闸前挂接）
＋席内本票径（SeatAdmin `set_project` 限本票）＋存量回填径
（`AdminGateway.SetTicketProject` RPC＋`meta ticket set-project` CLI）。
共用机械闸 `attachProject` 五判：`""→P`/`P→P` 放行、`X→Y` 拒、
未登记项目拒、部署中/终态拒；写后 `project_set` 事件留痕。

### 2. 为什么

部署闸对一切票不可服务：`ticket.project` 全表空（字段列明未落、无生产
写径），exec 闸「无配方登记」必拒；闸前十张 `待部署` 票（0003–0012，
码已实际并入主干并在线）因无挂接永不到完成。空 project 同时使项目锁
退化（全聚 `""` 键桶＝全表串行；设计锁对空票跳过＝不串行）。

### 6. 验收锚（全部机器可判）

1. `go build ./... && go vet ./...` 绿；`go test -count=1 ./...` 绿（原文
   tee）；`bash scripts/selfcheck.sh` 绿。
2. `protoc` 重生成三件（meta.pb.go/meta_grpc.pb.go/metav1connect）与交付
   逐字节一致（byte-identical——防手改 pb）。
3. `NewTicket{project:未登记}`→CreateTicket 拒（票不立）；
   `{project:stub}`→ticket.project==stub。
4. `DispatchReq{project:P}`→派发后 ticket.project==P 且 `project_set`
   事件在（actor/prov 断言）；**挂接在取锁闸前**——派 `待部署` CTO 票
   后 `projectLocks[P]` 占用（非 `""` 键）。
5. SeatAdmin `create_ticket`：`nt.project` 空→子票 project==派发票 project；
   显式→落显式值；未登记→admin_resp false 票不立。
6. SeatAdmin `set_project`：`ticket_id`≠本票→admin_resp false（事件无写）；
   本票→落＋`project_set` 事件。
7. `SetTicketProject` RPC 五判全验：未登记拒／`部署中`相位拒／终态拒／
   `X→Y` 换挂拒／同值幂等 ok 且无重复事件。
8. `Requirement{project:P}`→需求票落地 ticket.project==P。
9. CLI：`meta ticket set-project` 子命令通（桩断言 RPC 载荷）；`new/
   dispatch/require --project` 旗落参。
10. `project_set` 事件行进 `ticket_event` 且 emit 出（观察者断言）；
    caster `DispatchAction.project` 字段映射通。
11. **对抗性锚（≥3，变异必红）**：a. `attachProject` 换挂判等翻（`!=`→
    `==`）→换挂票挂上（锚 7 红）；b. `DispatchSeat` 挂接点挪到取锁闸
    **后**→`projectLocks[P]` 空（锚 4 红）；c. 登记校验删→未登记项目
    挂成功（锚 3 红）；d. `set_project` 越票判删→席位改写他票 project
    （锚 6 红）。
