# 新片规约（T53 慢偿配套·防再犯）

凡写 gateway 包测试片，钦定两则：

## 一、凡真子进程片

经 `spawnSeat`/`DispatchSeat`/cli-drive/调和器内起席等任何径起真
子进程的片＝集成片，必须有集成标记（`shortSkipInteg(t)` 或
`newTestGateway` 建闸面判自动判）——部署闸 `-short` 口径下摘帽，
开发全量片照跑。禁漏标（T51 四轮实证逐函数漏标必犯）。

## 二、凡等待片

禁裸 `time.Sleep`/裸 `time.After` 押窗——等待一律经：

- `waitPhase(t, g, id, want, timeout)`：事件订阅驱动（EventCh
  扇出道，事件到即醒）；timeout 只作安全网非节奏源。
- `waitFor2(t, d, ok, g)`：带 gw 参数＝事件订阅驱动条件等；
  不带则回退轮询（兼容非网关条件）。
- 断言语义对「条件到达」非「窗内必达」——窗是兜底，醒是事件。

墙钟押窗（固定时长的「应该到了」）一律禁——慢环境必饿死。
