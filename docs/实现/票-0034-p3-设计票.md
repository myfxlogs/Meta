# 票-0034-p3：deploy 步 restart 杀全席——设计票（CTO-A）

### 1. 目标

需求「deploy 步 restart 灭 meta-gateway cgroup 满门→部署永远不可收口」的
机制级修复设计：产出设计文档并 commit 到仓；本票八栏回填成可审设计票；
按设计立子票并完成真派发；Deliver 本票至待审。设计票本身不变施工票。

### 2. 为什么

巡检自立案（0034-p3，spawn_needed:对账补发 CTO-A）：票 0034 部署 24 连败
零 deploy_ok/retro——restart 杀席是必然，自检/回退段死码，deploy_done
唯一径寄生于必死之席，连坐灭全席再误判。复核属实：Do restart 后段不可达
（upgrade.go）、cmd_run 行写不出（runExecStep rec 在 Wait 后）、启动对账
先于 Serve（Probe 恒红）。CEO 定向＝§1.4 钦定轨。

### 3. 范围内

- 设计档 `docs/实现/设计-0034-p3-部署态判收口与席位scope豁免.md`（实证
  复核+机制设计+时序+残险+§11 落地对账），commit 到仓。
- 本票八栏回填（本文件）；`set_project meta` 自补漏挂。
- 立子票 0043（全量八栏·残面收缩版——实现主链已由并行链 728adeb 先合）
  ＋dispatch 施工（注入机径 workdir=/opt/meta）。
- Deliver 本票→待审（ref=设计档 commit）。

### 4. 范围外（禁线）

- 不写实现码不动测试（CTO 禁线）；不审实现（审计他席）；不 Deploy 不并
  master；不改票 0034 交付物/相位/事件；不并修邻票；设计档不代票。

### 6. 验收锚

1. 设计档在仓且 commit（`git log --oneline` 可见，含落地对账表）。
2. `meta phase --ticket 0043` 出票且 `events` 见 dispatch 行（子票立+派真）。
3. 本票 `fill_spec` 受理 ack（八栏非空闸过）＋`set_project meta` ack。
4. 已合并件三洞（deployStateOK 判据 cmd_run 不可得/Probe 早于 Serve、
   checker 证据未落 exec-log、收养无幂等）在设计档 §11 记档且入 0043。
5. 对抗锚：设计档/子票须含「反删即红」提名位（pending 消费删行/态判
   判等行/收养幂等闸行）——缺则子票锚 8 无源。
