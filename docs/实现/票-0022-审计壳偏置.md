# 票 0022：审计重派壳偏置——同壳连败 N 次本轮跳过（D-46）

## 1. 目标

`dispatchOnce` 在 `req.role=="审计"` 时，对候选序做**连败偏置**：取本票
seat_run 中 role=审计 非 adjunct 的 run，新→旧逐壳算尾部连败（Dead 且
ExitCode≠0，遇他壳或 ExitCode==0 断计）；连败 ≥N（默认 2，配置
`audit_shell_skip_streak`）的壳从本轮 attempts 剔除＋emit
`audit_shell_skip` 事件（note=壳名+连败数）；剔空照旧 shellsExhausted。

## 2. 为什么

- 决策 74 实证：审计席死→重派循环烧穿 opencode 免费日限（0015×6/0016×8
  audit_dead 风暴）——D-42 类席位级死因不进 failSet 不迁健康（D-40 原则
  正确，壳不背席锅），同壳被无限重试＝单壳烧穿。
- 偏置只「本轮跳过」不标壳坏——不碰 D-40 分级语义；连败数满让位他壳，
  壳尽自然停（shells_exhausted→CEO 裁），防单壳循环烧穿。

## 3. 范围内

- `proto/meta/v1/meta.proto`：网关配置消息加 `audit_shell_skip_streak`
  （int32）→ protoc regen（命令：`protoc -I proto --go_out=.
  --go_opt=module=meta --connect-go_out=. --connect-go_opt=module=meta
  proto/meta/v1/meta.proto`，实测幂等）。
- `internal/config/config.go`：解析落 `GatewayConfig` 新字段；
  `config/gateway.textproto` 落 `audit_shell_skip_streak: 2`；
  `cmd/meta/main.go` 接线（旗或纯配置径，随既有字段惯例）。
- `internal/gateway/dispatch.go`：dispatchOnce 壳序成后、preferFirst 前
  （或后——序内剔除语义一致即可，施工自裁但须注释码位）插偏置段：
  role=="审计" 且 N>0 才生效；剔除同时 AppendEvent+emit `audit_shell_skip`。
- 测试：internal/gateway 测试面新增（helper_test 开库/造 run 惯例）。

## 4. 范围外（禁线）

- 施工/CTO 角色不加偏置（D-46 钦定面＝审计重派）。
- 不动 route.NextHealth/failSet/health 列语义；不改 caster/路由表/席位。
- 不动在飞席位与在途票；不部署、不并 master；不碰生产 DB。
- N 值除配置落 2 外不写死第二处（config-out-of-code，D-9）。

## 6. 验收锚（全部机器可判）

1. **A1 连败跳过**：新测绿——票 t 造审计 run 行：devin Dead ExitCode=1 ×2
   （最新两枚）→dispatchOnce 后 devin 不在实际 spawn 候选（断言
   reportShell/trySpawn 未触 devin，或伪 spawn 记录断言 attempts 序无
   devin）；ticket_event 有 `audit_shell_skip` 行 note 含 devin。
2. **A2 阈值边界**：同壳仅 1 败→不跳照试；连败 2 但中间夹 ExitCode==0 成功
   行→断计不跳。
3. **A3 角色隔离**：同构连败发生在 role=施工→偏置不生效（attempts 照原序）。
4. **A4 剔空归宿**：全部候选壳连败达标→走 shellsExhausted 径（事件在）。
5. **对抗锚**（必红证）：删连败比较/剔除行→A1 红（devin 被重试）；翻
   ExitCode 判定（!=0 改 ==0）→A1 红。施工实跑留变异记录。
6. **A5 全量**：`go build ./... && go vet ./... && go test -count=1 ./...`
   绿；`gofmt -l` 零；`bash scripts/selfcheck.sh` 绿。
