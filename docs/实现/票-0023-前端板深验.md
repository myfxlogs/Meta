# 票 0023：前端板深验——最小 Connect 客户端拉 3 帧验收脚本（半活→已验）

## 1. 目标

`scripts/board-verify.sh`：scratch 自举端到端验收——建独立 DB/socket 的
scratch 网关＋board_listen，用 `meta board --connect`（Connect 二进制径，
与浏览器同一协议面）拉 ≥3 帧，断言帧型达标；`--live` 旗对生产
`127.0.0.1:9712` 同径复验。交付后前端板状态由「半活」升「已验」。

## 2. 为什么

- 决策 71 纸面率实测：前端板「监听与路由在、页面与帧未验」＝半活；钦定补
  验径＝最小 Connect 客户端拉 N 帧。本票把「半活」变「已验」。
- 板面与事件链任一断点（token 闸/Connect 挂板/全态组装/变化帧泵）都会让
  脚本红——一次脚本跑通＝全链在。
- 验收脚本入库＝后续任何板面回归一条命令复验（机器可判）。

## 3. 范围内

- `scripts/board-verify.sh`（新建，bash，set -euo pipefail）：
  1. scratch：`TMP=$(mktemp -d)`，`meta secret put --db $TMP/meta.db
     --key $TMP/vault.key secret.board.token`（值读 stdin 既定径；key 缺
     则脚本先造或按 put 报错现形——实现以现码行为为准）；
  2. `meta serve --db $TMP/meta.db --socket $TMP/meta.sock --rundir
     $TMP/run --board-listen 127.0.0.1:$PORT &`（$PORT 脚本内取空闲口，
     如 `python3 -c`/`ss` 探测或高端口试错）；
  3. `meta ticket new --socket $TMP/meta.sock --id vfy-a --title 验A`
     （先于接入→FULL 帧含非终态票）；
  4. `meta board --connect http://127.0.0.1:$PORT --token tok --n 3 >
     $TMP/frames &`；
  5. `meta ticket new ... --id vfy-b && meta rule --action void --ticket
     vfy-b --confirm`＋`meta rule --action void --ticket vfy-a --confirm`
     （void→phase:void emit→TICKET_UPSERT 帧；FULL＋2 upsert＝3 帧达标）；
  6. 有界等待 client 退出（≤15s）→断言 rc=0 且 frames：`FULL ` ≥1 行、
     `TICKET_UPSERT` ≥2 行；trap 清场（杀 serve、rm -rf $TMP）。
  7. `--live` 旗：读 `$META_BOARD_TOKEN` 对 `--connect
     http://127.0.0.1:9712` 同径打 `--n 3`，同断言（生产复验径）。
- 范围即这一件脚本；现码面（board.go/main.go/meta board CLI）已足，
  不应需改——实测揭真 bug 则停手申报（禁顺手修范围外）。

## 6. 验收锚（全部机器可判）

1. **A1 正锚**：`bash scripts/board-verify.sh` rc=0，stdout 末行
   `BOARD_VERIFY OK full>=1 upsert>=2`（或同义机器可读行）；frames 档
   `FULL ` 行 ≥1、`TICKET_UPSERT` 行 ≥2。
2. **A2 反锚**：对未挂端口跑（脚本支持 `--connect` 覆盖或验死地址变体，
   如 `BOARD_CONNECT=http://127.0.0.1:1 bash scripts/board-verify.sh`）
   →rc≠0（不绿放行＝脚本真在验而非摆设）。
3. **A3 无泄漏**：脚本退出后无残留 `meta serve` 进程（`pgrep -f
   "$TMP/meta.sock"` 零）；TMP 已清。
4. **对抗锚**（必红证）：把断言阈值 TICKET_UPSERT≥2 改 ≥99→脚本红
   （证明断言真卡帧数而非恒绿）；施工实跑记录。
5. **A4 全量**：`go build ./... && go vet ./... && go test -count=1 ./...`
   绿（本票无码改，回归哨）；`bash scripts/selfcheck.sh` 绿；
   `bash -n scripts/board-verify.sh` 绿。
