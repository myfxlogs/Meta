现象：stub sudo 用 `printf '%s\n' "$@"` 记 argv——**每个参数一行**，后续
`grep "META_EXEC_STEP=x.*bash"` 断言同行为空，误判 sudo 根本没被调。
一句话教训：想「一次调用一行」用 `"$*"`（IFS 首字符拼接）；`"$@"` 在
printf 里是逐参数展开成多行。捕 argv 做断言先看清是哪种展开。

## 解法
stub 记法固定：`printf '%s\n' "$*" >> log`；剥旗后 `exec "$@"`（执行侧
仍用 "$@"——argv 语义不能塌成单串）。
