# 哨兵失明三壳谱系——JSON 包裹型与行合并型

**现象**：席位 stdout 末行哨兵（`META_VERDICT`/`META_DELIVER`/`META_ADMIN`）
发出而网关无捕获——发信人无恙、接收器聋，表象＝净退席死循环。

**谱系（按壳分，勿混治）**：

| 壳 | 失明形态 | 机器证据 |
|---|---|---|
| claude | stream-json 壳流：哨兵被包进 JSON 字符串（assistant 文本/`tool_use` input——判决档本体末行即哨兵会随 Write 工具过流），行首锚定永不命中 | `run/logs/fa7aa447*`：判决实录在 JSON `text`/`content` 串内 |
| opencode | 同上（`--format json` JSONL） | 四班审计 exit=0 无判决（决策 60） |
| devin | 文本壳但**渲染层吃内嵌换行**：哨兵或与下段并同一物理行（行首锚定失效），或居行首但**载荷被粘文污染**（`fill_spec|path` + 粘文 → file name too long）；间歇性——跨渲染分块才并 | `run/logs/ca93f994*`:3 实录；e0b4355c/15bcd163 净行对照 |

**正解**（票 0017 落）：扫描点移到适配器解析后文本流（壳无关）＋
`$META_ART_DIR/sentinel.log` 文件双发兜底。substring 扫描是伪解——
哨兵载荷无自闭界（粘文/路径/CJK 同字符域），行中旁注成伪命中。

**救急绕行**（修复前二进制上 devin 哨兵被并）：往 devin 进程 fd 1
直写独占行——`echo 'META_X:...' > /proc/$(pgrep -f 'devin -p'|head -1)/fd/1`
（req-9ce5 施工席实证，席位扫描的是 devin 的 stdout 管道）。
