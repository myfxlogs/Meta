# 经验库

> **业主令 2026-11-01：遇到就写，不等统一归纳。** 一坑一文，写完即 commit。

## 纪律

- **触发**：任何坑被解决的当下——不管是绕过了、修好了、还是判明「暂不处理」——都写。不写＝违规，同「决策不留痕＝违规」。
- **形制**：每文头四行——`日期 / 席位（谁遇到的）/ 现象 / 一句话教训`；正文四段——环境、复现、解法或绕法、引用（票 / commit / 日志行）。
- **命名**：`YYYY-MM-DD-<主题slug>.md`。不做分类学、不做目录树——检索靠 grep，排序靠文件名。
- **注入**：阶段 2 起网关注入角色卡时附带本目录文件名索引（机械实现）；此前手工径自查。
