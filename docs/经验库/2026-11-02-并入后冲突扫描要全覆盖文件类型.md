# 并入后冲突扫描要全覆盖文件类型

**事故**：六支并入时 `.go` 文件的 `<<<<<<<` 扫了三遍清零，go build/test 全绿，
二进制都换装晋升了——`systemctl restart` 失败：`gateway.textproto:28
invalid field name: <`——0012 的 board_listen 冲突残块躺在 **textproto**
里，.go-only 扫描永远看不见。网关启动即死。

**规矩**：并入收尾的标记扫描一律全类型，不许按语言过滤：

```bash
grep -rln '<<<<<<<\|>>>>>>>' . --exclude-dir=.git --exclude-dir=.gomodcache \
  --exclude-dir=.gopath --exclude-dir=node_modules --exclude-dir=run
# 命中只剩二进制字节巧合（bin/*）才算清
```

**同源教训**：`go build` 绿 ≠ 可部署绿——配置文件不进编译面。
换装三件套的自检兜住了（服务没起来→回退径在），但扫描前移省一轮。
