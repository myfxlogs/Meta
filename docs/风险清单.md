# 风险清单

> 2026-11-01 设计席自评。给接手者当路标：**哪些是改不掉的，哪些是没跑过的，哪些已有管理**。
> 与总设计不矛盾——本文是风险的诚实登记，不是新增需求。

## 结构性（改不掉，只能管理）

| 风险 | 本质 | 已有管理 | 残余 |
|---|---|---|---|
| 网关单点 | 唯一写者=唯一故障点；它死则事件静止、飞书断、CEO 盲 | 启动对账 / OnFailure 回滚 / systemd 拉起 | **网关自身 bug 无兜底**——自举后 meta 的交付也走它 |
| LLM 审 LLM | B2 管住「锚造假」管不住语义放水；异壳换 vendor 不换 blind spot | 异壳审计 + 判决留痕 | 质量下限=审计席下限（R1 代价） |
| CEO 全权不可逆 | A10 放权后 CEO 可作废/启策略/追加预算 | 重述确认（作废/杀）+ 留痕 + 可逆性原则 + 最新指示优先 | 其余不可逆裁决靠 CEO 自觉升级——软约束 |
| 无状态 vs 连贯 | CTO 每事件一实例，一致性全靠读仓文档 | 角色卡必读 | 提示词约束非机械闸 |

## 纸面（未实证）

- 自举未验证：阶段 0–1 尚走手工径，整体未跑通
- 自动票爆炸半径：哨兵误报→成票→施工→可部署；「持续异常永远一票在修」形态可能烧预算帽
- 壳适配器未知面：三 CLI 是否都能前台 exec（B5）、流是否都带用量、无交互是否真不问——阶段 1 实测

## 保险带（阶段 0 随票补，一页纸）

- 配方旗 `auto_deploy_requires_ceo`（O 类钱径默认开，meta 自关）
- 重述确认帧适用类：从「作废/杀」扩为**配方可配的不可逆类清单**

## 已接受的残余（勿再议）

- 不加第二道 LLM 审查/第二脑——成本翻倍且错误相关；先跑阶段 2 拿审计放行率真数据再裁
- 不搞集群化网关——复杂度癌；单二进制+对账+回滚已覆盖本规模
