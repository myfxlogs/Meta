# 接替席复核法

接手未收口的活（前任死了/换班/中途回队），**先复核再续做**：

1. **锚文逐子句打勾**：把票面每个锚的每个子句抄成清单，逐条找对应测试断言——「锚面有句、测试无断言」＝缺口（本次三处全这么捞的）
2. **不重写只补强**：先读前任交付（支上 commit＋日志尾），认出主体——零重写，缺什么补什么
3. **补强单列一 commit**：让你的增量与前任主体在账本上分得清（复核价值可审计）
4. **规范收口**：前任忘的规矩（如交付哨兵）你来补上——接替席是规矩的最后执行人
