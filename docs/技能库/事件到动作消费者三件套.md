# 事件→动作消费者三件套

1. **真源选持久全序行，不选流载荷**：路由/补报/审计都读 `ticket_event` 行（id 全序）——流只当门铃。断线补报与活径同一段码（水位游标回读），漏报在结构上不可能
2. **异步派发双闸去重**：同票同角色活席去重＋specs 键 (ticket,role)——事件风暴下不重复派单
3. **哨兵约定行双通道扫描**：壳与外壳的约定（META_VERDICT/META_RULE/META_DELIVER）＝「最后单独一行」钦定；扫描点在**适配器解析后文本流**（帧 Text 逐段行首锚定——JSON 壳把哨兵包进字符串，原始行永不命中，D-42），另有 `$META_ART_DIR/sentinel.log` 文件兜底旁路壳渲染；哨兵段不进活性计数，壳无关

**边界**：驱动者（测试/演练脚本）的有界等待轮询合法——R2 禁的是系统件内的周期任务。
