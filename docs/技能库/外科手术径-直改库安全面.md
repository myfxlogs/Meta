# 外科手术径：外部直改库的安全面

沉淀日：2026-11-02
来源：票0011 收队、req-f88 三连错配纠正、D-56 毒行修复（≥4 次实战）
沉淀依据：四次手术三次踩坑（错配重发/尸体挡闸/毒行停摆）后全链验证绿
适用：CEO/业主上身位——席位或相位卡死须外部纠正、不走票务流水线时

## 允许面（只许 UPDATE）
- `ticket.phase`：相位重置（如错配清理→已立）
- `seat_run.dead`：收尸——但能只杀进程就只杀进程（先标死绕过角色分流）
- `ticket_event.kind`：残账废种（`spawn_needed`→`spawn_needed_stale` 防重放误派）

## 禁手面
- **禁手工 INSERT ticket_event**——created_at 纳秒整型，datetime() 毒死 Observe 流（D-56）
- 禁改 seat_run 其余列（attach/adopted/exited 归网关写）

## 流程
1. 改前查 `run/caster/watermark`——未消费事件会重放，残账先废种再放行
2. UPDATE 后 `meta reconcile` 或等对账——状态机自接管后续
3. 验证三件：票相位＋新 run 角色/壳＋提示件血统（`run/caster/prompt-*.md` 头行）
4. 留痕走 `meta inject`（actor=ceo），禁裸 SQL 插事件
