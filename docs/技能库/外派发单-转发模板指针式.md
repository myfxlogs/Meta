# 外派发单·转发模板指针式

> 沉淀日：2026-11-02｜来源：业主令（固化转发模板）｜依据：换壳换CEO后模板
> 不得自撰变形；票面档会换，模板不随档｜适用：CEO 给业主发外派施工提示词时

## 转发模板（唯一真源——一切外派单照抄此式，禁自撰形制）

```text
[角色:施工] <单号>（票<票号> <题名>）：票面全文＝<票面档绝对路径> §<节号>；
仓库 /opt/meta（Go）；规约＝认领即锁建支 t/<票号>-<slug>＋翻单commit＋push，
commit 头 [角色:施工][<单号>]，收口＝票面要件＋通用核A–I自检＋结果回填；
红线：不引定时器/轮询、不碰master、不部署、不改票外无关文件；
交付＝分支＋改动清单＋build/vet/test 输出尾20行。
```

## 四要点（违反任一条＝形制错）

1. `[角色:施工]` 必须开头——壳按此入席。
2. 票面只指「档路径＋§节号」，**不内联上下文**——票面档是唯一真源，
   提示词里再写一遍＝双写必漂。
3. `<票面档绝对路径>` 填**当期票面档**（现行为
   `docs/实现/外派施工提示词.md`；将来换档只换占位值，模板不动）。
4. 票号取票面括注的**原票号**（非单号 T<N>）；一单审回再发下一单。

## 修订

模板本身改动＝业主令级（宪法级形制），记 ceo_memory＋改本文件；票面档
头部与各单提示词只留本指针，禁各自抄模板。
