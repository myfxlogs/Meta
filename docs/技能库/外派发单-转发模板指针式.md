# 外派发单·转发模板指针式

> 沉淀日：2026-11-02｜来源：业主令（固化转发模板）｜依据：换壳换CEO后模板
> 不得自撰变形｜适用：CEO 给业主发外派施工提示词时

## 打法
1. 转发提示词照抄 `docs/实现/外派施工提示词.md` 顶部「转发模板」节，
   仅替换 `T<n>`/票号/题名三处占位。
2. `[角色:施工]` 必须开头；票面只指 § 编号，不内联上下文（票面档=唯一
   真源，双写必漂）；票号取票面括注原票号。
3. 一单审回再发下一单（决策 94 严格序）。

## 真源
`docs/实现/外派施工提示词.md`「转发模板」节——改模板只许改那一处。
