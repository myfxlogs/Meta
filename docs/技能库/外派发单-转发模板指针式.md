# 外派发单·转发模板指针式（o collab §3 出指令规程移植）

> 沉淀日：2026-11-02｜来源：业主令（采 o 仓出指令规程单行指针式）｜依据：
> 换壳换CEO后模板不得自撰变形；票面档会换，模板不随档｜适用：交互 CEO
> 给业主发外派施工提示词时（无头 CEO 不经此面）

## 转发模板（唯一真源——一切外派单照抄此式，禁自撰形制）

```text
[角色:施工] T<n> <一句话目标>（读票面全文：<票面档绝对路径> §T<n>）
```

实样：
```text
[角色:施工] T8 容器笼出闸三壳活体（读票面全文：/opt/meta/docs/实现/外派施工提示词.md §T8）
```

## 要点（o §3 精神——违反任一条＝形制错）

1. **单行指针**：上下文全压票面，禁把施工细节塞进提示词——提示词一旦
   多行＝细节溜出票面的信号，先把细节回填票面档再发。
2. `[角色:施工]` 必须开头——壳按此入席。
3. 规约/红线/领单规程全在票面档头部（o 仓压在 collab.md，我们压在票面
   档——外派壳不进仓无协议兜底，票面即协议）。
4. `<票面档绝对路径>` 填**当期票面档**（现行为
   `/opt/meta/docs/实现/外派施工提示词.md`；换档只换占位值，模板不动）。
5. 一单审回再发下一单（决策 94 严格序）。

头部与各单提示词只留本指针，禁各自抄模板。
