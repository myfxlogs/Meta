# 手工径：派票→查验→收口 全循环

## 一、派票（戴临时 CTO 帽）
1. 立票：`docs/实现/票-NNNN-<slug>.md`，八栏齐＋新形制（摘要五节含候选节·E4/E8；对抗性锚·E5；收口门·E9）
2. **过债务台账**：相关债写进「范围内」（E6/E7），commit 钉设计引用
3. 施工区＝metaseat 独立克隆：`git bundle create /tmp/t.bundle <支>` → `runuser -u metaseat -- git clone /tmp/t.bundle ~/worktrees/tN -b <支>`（**本地克隆撞 dubious ownership 就走 bundle 桥**）＋repo-local 身份 `devin-施工`
4. 注入前缀＝角色卡＋票面＋禁区＋CEO 定向＋经验库前置（模板见 `/tmp/t00NN-*-prompt.md` 历件）——**路径全绝对**（席位的 `~` 是它自己家）
5. 起席（技能《无头席位起法》）＋退出钩子 `notify-result.sh`

## 二、机械验证（CEO 代跑，不是审计）
- 四件：build/vet/test/selfcheck——原文落 `~/meta-worktrees/tN.machine-record.txt`
- live 件（冒烟）**不重跑**：抄施工留档为机器记录（省配额；施工自测各壳至少一轮是票面义务）

## 三、审计（devin swe-2-max·只读）
- 注入前缀＝角色卡＋票面（含判决史）＋材料清单（**先逐件 `runuser -u metaseat -- test -r` 预检可读**）＋特别质询＋「判决走 stdout」＋只读纪律起手钉死
- 二审起：增量 diff 为主审对象＋全量 diff 作上下文＋一审判决全文作判决史

## 四、收口
- **通过**：判决档入 `docs/实现/票-N-判决/`；票面头部标已完成＋判决史补段；台账清债（「清于」必填票号＋判决档）＋新债入账；`merge --no-ff` 并 master＋推 origin；README 状态；决策入 ceo_memory；飞书通知
- **驳回**：判决史全文进返修提示词（同壳重做）；定向＝驳回项逐条＋**根因义务**；台账记 planned:tN返修
- 席位区搬运回 `/opt/meta`：bundle 桥＋fetch＋CEO 代推 origin；旧施工间 `worktree remove`（分支被占时先拆旧间）
