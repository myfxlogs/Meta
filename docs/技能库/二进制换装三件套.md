# 二进制换装三件套

1. **换装＝原子 rename 晋升**：新版先落旁名（`bin/meta.new`），`os.Rename` 到正式名——**禁直接覆写运行中二进制**（ETXTBSY：内核拒写正在执行的文件，见经验库同日条）
2. **保留上一版**（`bin/meta.prev`）：熔断回退的唯一退路；晋升时 prev←旧版
3. **回退＝熔断触发**：连崩超限→rename prev→bin→恢复 serve；判据四件＝退出码＋sha256＋version 自报＋日志 grep

**边界注记**（判决要求）：驱动脚本（drill）里的有界等待轮询合法——**驱动者非系统件**，R2 禁的是系统内的周期任务。
