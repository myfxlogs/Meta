# 无头席位起法（三壳）

## 通用前置
- 提示词一律 `--prompt-file`（绝对路径）——`-p` 内联会撞路径参数
- 席位用户＝`metaseat`；`runuser -u metaseat -- env HOME=/home/metaseat PATH=<P> …`，P＝`/usr/local/go/bin:/home/mluser/.local/bin:/home/mluser/.npm-global/bin:/home/mluser/.opencode/bin:/usr/local/bin:/usr/bin:/bin`
- Go 三缓存重定向进工作区：`GOCACHE/GOMODCACHE/GOPATH=$PWD/.go*`（防沙箱/权限卡死）
- 产出（判决/摘要）走 **stdout 重定向落档**——别依赖席位的文件写权限
- 退出钩子挂 `scripts/notify-result.sh`（纯中文模板，勿透传席位原文）

## devin（施工席·全权档）
```
devin -p --prompt-file /abs/prompt.md --respect-workspace-trust false \
  --permission-mode dangerous --export /abs/usage.atif.json
```
- env：`DEVIN_MODEL=swe-2-high`（施工）/ `swe-2-max`（审计/诊断）
- 鉴权：`/home/metaseat/.local/share/devin/credentials.toml`（副本制，D-10 维护）
- 信任：`~/.local/share/devin/cli/trusted_workspaces.json` 只信自家

## claude（席位/备援）
```
. /home/metaseat/.claude-env   # ANTHROPIC_BASE_URL + ANTHROPIC_AUTH_TOKEN
claude -p --output-format stream-json --verbose --permission-mode acceptEdits --permission-prompts none < prompt.md
```
- 鉴权真源＝`profiles/glm.json` 的 env 块（非 `.claude.json`）——副本＝`.claude-env`＋`profiles/` 目录
- 用量在 `result` 帧 `usage`＋`total_cost_usd`

## opencode（尾位备援·每日限量）
```
opencode run --format json --auto --standalone < prompt.md
```
- 用量在 `step_finish` 帧 `part.tokens`＋`cost`；**当日配额尽＝②b 标死换壳，次日懒探自愈**

## 只读席位（审计/诊断）
- 默认权限档即可，但提示词**起手钉死**：「只用只读文件工具（读/搜/列目录），不跑任何命令；git 态直读 .git 内文件核」——否则它起手想跑命令即被拒、草草收场
