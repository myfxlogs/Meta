# 设计-T21 网关降权迁移（mluser→metaseat｜两段式·先设计后施工｜D-24）

## 1. 病根
网关与 spawn 席位全跑 mluser（业主主账）——模型席与业主凭据同权同
HOME，凭据隔离只剩 scoped secrets 一层；vault.key/meta.db/席位凭据
与业主全量资产同权限域。降权后席位域只够拿自己 run 的凭据。

## 2. 迁移对象盘点（现状实证）
| 对象 | 现状 | 迁移后 |
|---|---|---|
| systemd 单元 | `~/.config/systemd/user/meta-{gateway,caster,gateway-notify}.service`（mluser user 域，`systemctl --user`） | 移到 metaseat user 域（`loginctl enable-linger metaseat`），或转 system 域 `User=metaseat`——**定夺：转 system 域**（user 域依赖 login 会话，生产部署面更稳；代价=sudoers 面扩大） |
| /opt/meta/run 归属 | mluser:mluser（vault.key 0600、meta.db 0600、socks/logs/secrets/workdirs） | `chown -R metaseat:metaseat /opt/meta/run`；bin/config/roles/docs 保持 root 或 mluser 只读——**只迁 run/ 写域** |
| 席位 argv/PATH | `Environment=PATH=/usr/local/go/bin:/home/mluser/.local/bin:/home/mluser/.npm-global/bin:/home/mluser/.opencode/bin:...`——壳 CLI 全在 mluser HOME | **最硬骨**——devin/claude/opencode 二进制在 `/home/mluser/.local/bin`：方案 a 装 metaseat 独立副本（干净但三壳各装一遍）；方案 b `chmod o+rx` 相关目录（泄露面扩大）；**定夺：方案 a——shell 表增 `bin_path` 列或统一 `/opt/meta/shellbin/<name>` 挂接径**（运维卡已预留 cage CLI 挂载同构面） |
| vault.key | mluser 0600 | metaseat 0600（secret 表随库走不解密重灌） |
| sudoers 面 | systemctl --user 无需 sudo | 转 system 域后 restart 需 `systemctl restart meta-gateway`——sudoers 追加 `metaseat ALL=(root) NOPASSWD: /usr/bin/systemctl restart meta-gateway, /usr/bin/systemctl status meta-gateway`（deploy 步 restart-cmd 同配）；**或**保 user 域 sudoers 免改——两径在设计审定夺 |
| 席位 spawn uid | `cageArgv` 同 uid 用户跑（`user.Current`/`os.Getuid`） | metaseat 自跟随——spawn 子进程 uid=metaseat（无 sudo 跨 uid 需求） |
| 凭据/容器笼 | secrets dir 0555/0444（T18 只读面） | 目录属 metaseat——同 uid 降权后 chmod 回改面收敛（T18 残面顺带缓解） |
| ceo-present.json/交互席 | run/ 下在 mluser | 随迁（交互席读 run/——业主侧读径不变，权限位保） |

## 3. 迁移序列（五段，逐段可回退）
1. **立户**：`useradd -r -m -d /home/metaseat -s /usr/sbin/nologin metaseat`
   （或 system 用户无 HOME＋显式 rundir——按方案定夺）
2. **装壳**：`/opt/meta/shellbin/{devin,claude,opencode}` 挂接/副本＋
   `shell` 表/seed 指新径（三壳各验 `--version` 绿）
3. **迁单元**：写 `/etc/systemd/system/meta-{gateway,caster}.service`
   `User=metaseat`＋`WorkingDirectory=/opt/meta`＋同 EnvironmentFile
   径迁 metaseat HOME（或 user 域 `loginctl enable-linger`）
4. **迁写域**：停服→`chown -R metaseat:metaseat /opt/meta/run`→
   sudoers 行（system 域径）→启服→健康自检绿
5. **验真**：起一张测试票全程走完（deliver→done）＋secret RPC 一发
   ＋deploy 步 restart 径一次

## 4. 回退
`chown -R mluser:mluser /opt/meta/run`＋起 mluser 单元（原 unit 文件
保留在 `~/.config/systemd/user/` 未动——双单元并存期禁同时启，用
`meta-gateway.migrated` 标记文件机械闸防双网关写库）。

## 5. 风险与残面
- **壳 HOME 依赖**：devin/claude 读 `$HOME/.devin*` 会话档——降权后
  首跑重建档（续会锚 `META_RESUME_SESSION` 历史不可续，一次性损耗
  如实申报）
- **systemd-run --scope**（0034-p3 席免连坐）在 metaseat user 域同
  形可用（`systemd-run --user --scope`——须 metaseat login 会话或
  linger）；system 域径下 scope 退化直跑（残面申报）
- **secrets 文件属主**：已有 run/secrets 目录 chown 随迁；新落文件
  以 metaseat 属主（T18 权限位不变）
- **飞书/caster 单元**：同迁（同一凭据域——secret.feishu 解密权须随
  vault.key 走，caster 不迁则飞书面脱钩）

## 6. 决策点（CEO 裁定项）
1. **system 域 or user 域**：user 域=sudoers 免改但依赖 linger+登录
   会话；system 域=生产稳态但 sudoers 行扩——设计推荐 **user 域**
   （最小变更面，`meta-seat` 网已建可直连）
2. **metaseat 立户形态**：nologin+system home `/opt/meta`（无 HOME
   依 赖 ）vs `-m /home/metaseat`（壳 CLI 档挂 点——devin/claude 档
   需可写 HOME）**推荐 -m**（壳档落点必备）
3. **三壳挂接径**：`/opt/meta/shellbin/` symlink 统一径 vs 每壳独装
   ——推荐 symlink 统一径（运维卡同构）
